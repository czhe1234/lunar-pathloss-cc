# C4 几何补充版本

沿用 C3 已训练权重，新增临界 TX 高度、临界 RX 高度、TX3 与 TX2 敏感性两种直线几何中的累计地形内长度。长度在相邻剖面采样点之间线性求交，再累计，不把采样点数量直接当长度。
这是地形几何描述，不生成任何传播功率、仿真标签或伪 PL 标签。实际 FSPL 仍按官方 TX3/RX1 与 415 MHz/5.775 GHz。
新增输入权重初值为零，其余权重继承冻结的 C3 最佳开发检查点。固定开发地形不变。只用开发集选轮；官方验证未读取。
配置：24 轮上限、lr=0.0003、batch=32、耐心 8。仍用原掩码 MSE 与同地形 TX 配对监督，不新增类别损失。所有执行限定实体 GPU3 UUID。
C3 20 轮后停止，最佳第 16 轮，开发 RMSE 3.787123 / 4.805844 dB。C3 有改善但远未达到 1 dB；保留其原始记录和检查点。
标签与掩码改为 CPU 内存映射读取，输入几何继续常驻 GPU，以容纳新增特征。掩码不进入模型。
