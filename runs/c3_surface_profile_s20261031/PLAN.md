# C3 运行定义

最新用户授权：直接实施和训练，交付双频官方验证 RMSE 接近 1 dB 的版本。
主假设：显式分段净空、双端可见表面几何，以及同地形多 TX 附加衰减监督，能改善阴影范围与阴影内变化。
只用官方发布原始数据和 CC 独立实现。全部计算在实体 3 的 UUID 下。禁止新增传播仿真数据。
训练只读 train 标签，模型选择只用固定 dev 地形；官方 val 只在冻结模型后用于最终验收，不据其调整结构或选轮。
主要指标：双频各自原掩码 pooled RMSE；同时复核深遮挡 TX 变化与边界错误。
保留完整失败和中间结果。输出实际分数，不把启动、辅助指标或开发分数说成 1 dB 达标。

实施定义：
- 256 个中点路径采样，保留 8 段最大净空；另算 TX2/RX1 高度敏感性，不更改元数据的实际 TX3/RX1 高度。
- 16 个方向、16 个非均匀距离的地表候选。使用视线地平线和 TX 可见性构成 3 个距离层的共同可见面比例及最小额外几何路程。它们是几何代理量，不是真实传播路径或功率。
- 11 个基本输入通道与 16 个几何通道，约 898 万参数残差 U-Net，低分辨率全图注意力，逐像素几何直连输出头。精确几何、输入投影、输出头 FP32，其余 BF16。
- 输出 = 两频段自由空间距离项 + 网络附加损耗。没有硬性 LOS 或遮挡输出约束。
- 固定 fit/dev 地形划分，AdamW，最多 60 轮，2 轮热身后余弦下降，开发集耐心 12。每四个批次加入一次同地形近邻 TX 成对监督，权重 0.25。
- 本次不使用 D4 数据增强。理由是已观察到标签栅格与 TX 的固定方向偏移，尚无证据证明该生成偏差严格随 D4 协变。保留几何旋转一致性检查。
- 多项修改作为一个候选整体评价。本轮不能据此声称某个单独组件已通过消融证明有效。
- 官方 500 ms 限制将用完整输入到双频输出计时复核，分别记录冷启动与预热。服务器测时不能替代尚未确认的官方硬件条件。
