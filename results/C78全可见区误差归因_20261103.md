# C78｜C76 全可见区的大误差来自哪里

2026-11-03。频段顺序均为 415 MHz、5.775 GHz。下文的标签是比赛发布的仿真总路损。

**C76 确实把一部分对地形很敏感的接收位置归进了全可见区。另一大块误差发生在所有候选几何都判为可见、但标签功率比保守直达参考弱 3 dB 以上的位置。这一块占原全可见区平方误差的 45.15% / 40.22%。在已检查的候选中，精算镜面反射和漫散射只能补回很小一部分。**

C76 在完整官方固定验证集的 RMSE 为 **2.253301 / 2.596454 dB**，两频段算术平均 **2.424877 dB**。C78 是误差分析。训练门槛未通过，没有产生新参赛版本。

## 数据和比较口径

- 内部对照使用官方 TRAIN 中的 612 块地形。128 块、628 张图只用于校准小型线性诊断模型。另 484 块、1,934 张图用于确认效果。沿用 C76 的两条冻结分支及 50/50 权重。内部基础预测来自按地形留出的 C54，部署版基础预测来自全 TRAIN 的 C65。
- 先用这 484 块地形决定是否训练，再在官方固定验证集上复核。复核直接读取部署版 C76 已保存的预测，覆盖 680 块地形、每频段 2,330 张图。每张图均匀、无放回地固定抽取 2,048 个位置。按各频段原掩码，分别保留 4,735,799 / 4,249,191 个有效位置。它们的全图抽样 RMSE 为 2.252880 / 2.596430 dB。最上面的官方分数则按全部有效像素计分。
- 全可见沿用 C76 的原始定义。每个候选接收三角形采 9 个等面积子区中心，对周围三角形按像素插值权重合并，加权可见比例大于 99% 时入组。全可见分母固定为 3,439,024 / 3,439,381 个有效位置。子集内报告 RMSE，误差占比报告该子集的平方误差和除以同频段原全可见区的平方误差和。掩码仅用于计分。官方验证标签未参与拟合、选权或决定是否训练。

## 遮挡改判能覆盖多少误差

|---|---:|---:|---:|---:|
| 至少一种设置下可见率低于 90% | 11.20% / 11.20% | 35.24% / 40.08% | 27.51% / 31.81% | 3.153 / 3.530 dB |

表中第四列和第三列共用分母。几何敏感和功率偏弱会出现在同一点，不能把两者的误差占比相加。按地形重采样，第一行的平方误差占比 95% 区间为 **33.51%–36.95% / 38.39%–41.71%**。几何改判只能定位风险，原始网格上的真实遮挡比例仍未知。即使把第一行所有点的预测误差归零，其他点保持原值，原全可见区 RMSE 仍有 **1.430 / 1.444 dB**。内部 484 块确认地形也有相近结果，第一行约占 11.6% 的点、35.0% / 39.6% 的平方误差。

还做了比离散射线投票更严格的检查。用公布的高程，覆盖两种三角形对角线、候选发射高程再上下放宽 0.5 m、收发平面位置各放宽半格、接收高度 0.75–1.25 m。沿每束射线用地形最高点和射线最低高度作保守界。只保留能确认所有参与插值的接收三角形上处处通视的像素，排除图边界。在这个范围内能确认通视的点占 **64.16% / 64.16%**，仍占原全可见区平方误差的 **36.66% / 32.92%**，组内 RMSE 为 **1.343 / 1.336 dB**。这项保证只适用于重建的网格和给定坐标范围。独立 CPU 在官方验证的 64 块抽样地形上逐条复查，11,024 条此类射线均畅通。作为阳性对照，易遮挡组 12,288 条射线中有 9,035 条被挡。

## 反射和散射能否解释剩余误差

保持同一地形、发射机和接收单元，只切换功率分量。在保守确认通视的同一批官方验证位置，单次镜面反射尤其能改善高频物理估计。表内前三个附加功率组合均为独立求得的物理近似。官方仅发布总功率。

| 同一批通视位置上的预测 | 415 MHz RMSE | 5.775 GHz RMSE |
|---|---:|---:|
| 仅直达 | 1.926 | 2.048 |
| 直达和镜面反射 | 1.852 | 1.819 |
| 直达和漫散射 | 1.901 | 2.002 |
| 直达、镜面反射和漫散射 | 1.856 | 1.821 |
| C76 已有预测 | **1.343** | **1.336** |

再用同一组几何输入校正 C76，只改变是否提供精算的镜面反射和漫散射功率。484 块确认地形上，增加这两项使全可见区 RMSE 额外下降 **0.00064 / 0.00085 dB**。按地形配对的 95% 区间为 0.00055–0.00073 / 0.00074–0.00096 dB。与同图、相近距离、入射角和几何条件下打乱功率位置的对照相比，改善为 0.00064 / 0.00086 dB。在部署版官方验证抽样上，冻结的校正给出 **0.00071 / 0.00095 dB** 的额外改善。另在各 48 张图上提高镜面积分密度，增加漫散射采样并更换采样种子，校正后的 RMSE 变化均小于 0.0003 dB。镜面与漫散射为一次反射近似。漫散射强弱的固定绝对阈值没有可匹配的两组样本，单独的绝对阈值比较无法估计其作用。

## 通视时，模型具体漏掉了什么

**弱点定义。** 对每个频段，以候选几何给出的最大距离计算自由空间直达路损。若标签路损比它还大 3 dB 以上，记为一个弱点。在原全可见区，只有 **4.76% / 4.21%** 的有效像素属于弱点，却占 **73.39% / 72.85%** 的平方误差。限定在 C76 绝对误差至少 5 dB 的点上，这个占比升至 **88.91% / 88.21%**。弱点由标签定义，只用于分析。比赛的网格无线电图求解器将不同到达路径的非负功率相加。因此，如果完整直达功率已经到达，调低所有反射、散射至零也不能把总功率降到直达以下。[Sionna RT 1.1.0 单元功率累积](https://github.com/NVlabs/sionna-rt/blob/v1.1.0/src/sionna/rt/radio_map_solvers/mesh_radio_map.py#L102-L142)

**弱点和掠射有关。** 在保守确认通视的点内，固定同一张图和同一发射机，按传播距离和估计反射、散射总强度分层匹配。当超过一半的接收采样权重对应掠射方向时，弱点率为 **18.52% / 14.98%**。当该比例低于 5% 时，弱点率为 **0.27% / 0.23%**。掠射指传播方向几乎平行于接收面，方向和面法向夹角余弦绝对值小于 0.015。两频段每组的匹配权重分别为 400,958 和 401,453，覆盖 2,175 / 2,177 张图。按地形计算，两组发生率之差的 95% 区间为 17.70–18.76 / 14.13–15.34 个百分点。两个频段共同有效的 2,206,535 个通视位置上，C76 带符号残差相关系数为 **0.981**。低频弱点中 80.9% 在高频也弱，高频弱点中 99.7% 在低频也弱。这里的掠射指标是看到功率亏损后增加的探索性检查，内部和官方验证使用同一定义。

**能定位到哪一步。** 在上述通视范围内，C76 对弱点的检出率只有 **39.56% / 37.01%**。若要求直达功率保持完整，同时允许每个点任意选择非负的额外功率，逐点不可补回的平方误差与当前 C76 误差重叠至少 **72.15% / 68.01%**。计算时，逐点取“标签路损超出最大直达路损的正部平方”和“C76 平方误差”的较小值，再除以该组 C76 的平方误差总和。这是对完整直达假设的检验。它不限定任意模型能达到的最低 RMSE。

## 是否训练，以及怎样再区分原因

本轮只在 128 块地形上拟合诊断用的小型线性校正。启动新网络的预设条件是两频段在 484 块确认地形上同时达到全可见区至少 0.15 dB、全图至少 0.08 dB 的改善，且相对于匹配对照能明确归到一种物理输入的改善至少 0.05 dB。主要几何加反射、散射方案仅改善全图 **0.00136 / 0.00190 dB**。连同探索性的接收面表征，最大也只有 **0.00189 / 0.00240 dB**。因此停止这条训练分支。C76 距每频段 1 dB 的目标仍差 **1.2533 / 1.5965 dB**。

目前可定位到掠射处的有效直达功率。要继续分清有限射线命中和网格对应误差，需要同一地形的实际发射机坐标、原接收三角形，以及每个三角形插值前的直达命中数或仅直达功率。先查弱点对应三角形内的直达功率是否已经降低。如果三角形内正常而栅格像素变弱，就检查插值所用的三角形及其权重。若三角形内已偏弱，再用同一网格和发射机比较逐种子的命中数与仅直达功率。发布的两个总功率值不足以把这两步逐点拆开。[生成者对接收网格、随机种子和插值的说明](https://github.com/NVlabs/sionna/discussions/982)
