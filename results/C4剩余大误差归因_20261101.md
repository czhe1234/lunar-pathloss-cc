# C4 剩余大误差：证据与未定项

报告日期：2026-11-01。审计目录名 20261031 是本次运行标识。所有新分析在服务器 CC 独立完成。没有训练、优化器、反向传播、权重更新或新传播仿真。没有读取其他 AI 的工程代码、特征、模型或结果。

**判断：已证实当前模型连训练样本内的遮挡衰减和 TX 响应都没有拟合好；同时，点位净空与发布标签的衰减分区有稳定差别。没有证据把主要问题归咎于整图错配，也没有证据证明现有输入存在几 dB 的不可预测误差下限。**

必须区分“当前模型没有拟合好”和“这些误差全部可由现有输入学会”。前者已有直接测量；后者没有得到证明。下面的误差份额是位置/状态归类，不是数据、信息、模型三种原因的因果百分比。

## 1. 同一冻结模型：训练内误差已经很高

| 数据 | 地形数 | 图数/频段 | 415 MHz RMSE | 5.8 GHz RMSE |
|---|---:|---:|---:|---:|
| 匹配训练样本 | 680 | 2330 | 3.452014 | 4.177469 |
| 官方固定验证 | 680 | 2330 | 3.812677 | 4.990175 |

单位均为 dB。模型为 c4_full_refit_s20261031 的第 8 轮冻结检查点。训练组包含 33 块多 TX 地形和 647 块单 TX 地形，按 TX 数量组与地形起伏五档匹配官方验证；选样只使用地形和索引，不看标签或残差。训练组排除原内部开发地形，但这些样本都参与过模型训练。不是全训练集分数。

验证减训练的差值为 0.361 / 0.813 dB。按地形、并在匹配档内重采样 1000 次，95% 区间分别为 0.095–0.616 / 0.508–1.126 dB。TX 地图没有被当成独立地形。粗匹配仍不等于所有几何分布完全相同。

这说明泛化差距确实存在，但训练内误差本身就远高于目标。它不能进一步区分模型容量、优化过程、表征压缩和不可预测标签变化。不能据此断言“再训练就好”，也不能断言“训练永远无用”。

## 2. 大误差集中在哪里

E3 是 TX 高于当地地形 3 m、RX 高于当地地形 1 m 时，沿 TX—RX 直线的最大地形超出高度；E2 仅把 TX 高度改为 2 m，用作敏感性检验。E>0 表示该点位几何代理被遮挡。c 是接收侧地表法线与来向的余弦。所有分区来自输入几何，下面六区互斥且覆盖全部有效像素。它们不是真实逐径 LOS 标签。

| 几何区域 | 定义 | 有效像素占比 415 / 5.8 | 平方误差占比 415 / 5.8 | 区内 RMSE 415 / 5.8（dB） |
|---|---|---:|---:|---:|
| 高度敏感区 | E3<0 且 E2≥0 | 7.57 / 8.07% | 43.03 / 68.35% | 9.090 / 14.522 |
| 浅遮挡区 | 0≤E3≤2 m | 16.80 / 12.67% | 32.34 / 15.60% | 5.290 / 5.536 |
| 深遮挡区 | E3>2 m | 5.90 / 1.52% | 6.52 / 1.88% | 4.007 / 5.547 |
| 可见侧近边界 | E3<0，−0.5≤E2<0 m | 14.48 / 16.14% | 10.02 / 8.76% | 3.172 / 3.675 |
| 可见但近掠射 | E2<−0.5 m，abs(c)≤0.03 | 17.94 / 20.00% | 7.12 / 4.48% | 2.402 / 2.361 |
| 稳定可见区 | E2<−0.5 m，abs(c)>0.03 | 37.31 / 41.59% | 0.97 / 0.94% | 0.615 / 0.750 |

高度敏感区只有 7.57 / 8.07% 的有效像素，却贡献 43.03 / 68.35% 平方误差。若假设该区每个像素都被理想地预测正确，其他位置预测完全不变，整体 RMSE 仍为 **2.878 / 2.807 dB**。计算使用原始全部有效像素分母：sqrt((总 SSE−该区 SSE)/原像素数)。这不是可部署模型，不是删除像素后的分数，也不是对所有模型的误差下限。只能说明“只修这一块区域”不足以达到目标。

相对当前验证结果，达到 1 dB 需分别消除 93.12% / 95.98% 的总平方误差。只靠小幅改善不能填平这段距离。

用标签与预测各自的附加衰减 A=PL−FSPL 分成 <3、3–10、≥10 dB 三类，类别不一致贡献 47.11 / 57.66% SSE；标签和预测都≥10 dB，仍贡献 49.60 / 39.84%，该组 RMSE 是 5.416 / 7.612 dB。因此，识别“高衰减”还不等于学会其强度。这些类别是功率分区，不能替代真实传播机制。

绝对误差>10 dB 的像素只有 3.80 / 4.90%，却贡献 66.37 / 81.43% SSE。将残差投影为每个 8×8 块的有效像素平均值，仍保留 47.39 / 59.54% SSE。很多误差成片存在，不能全归为孤立坏点；空间相关也不等于已经证明可学习。

## 3. 双频差距主要落在同一高度敏感区

为了不混淆不同掩码，另取两个频段都有效的 **135,750,001 个相同像素**。在这些像素上，高频减低频的额外 SSE 中，**85.17% 位于高度敏感区**。这只是额外误差的位置归属，不是“85% 的误差由某个物理因素导致”。

扣除已知自由空间频差 20log10(5775/415)=22.8701 dB 后，高度敏感区真实双频差的标准差为 9.192 dB，预测只有 6.095 dB；双频差的预测误差 RMSE 为 7.676 dB。模型把这里的频率差异压小了。

全体共同有效像素的共同残差能量占比为 84.89%。共同项定义为 (e415+e58)/2，差分项为 (e58−e415)/2。这个代数分解不能当成“地形原因占比”。深遮挡区的共同份额仅 49.14%，所以也不能用统一的双频偏移去解释全部阴影误差。

## 4. 同一深遮挡内，模型对 TX 改变的响应仍不足

每块多 TX 地形内，每个 TX 配对最近的不同坐标 TX，再对无向对去重。固定每图 1024 个 RX。仅统计两次都满足 E3>2 m，且两张标签都有效的位置。先扣除各自距离的自由空间项，再比较附加衰减变化。

| 数据与频段 | 有效地形 | 有效 TX 对 | 配对 RX 观测数 | 标签变化标准差 | 预测变化标准差 | 变化预测 RMSE |
|---|---:|---:|---:|---:|---:|---:|
| 训练 415 MHz | 30 | 581 | 33,280 | 5.071 | 2.479 | 4.355 |
| 训练 5.8 GHz | 26 | 302 | 9,211 | 5.699 | 2.315 | 5.150 |
| 验证 415 MHz | 31 | 771 | 55,264 | 5.857 | 3.224 | 4.822 |
| 验证 5.8 GHz | 31 | 448 | 10,033 | 6.115 | 2.942 | 5.521 |

单位均为 dB。训练和验证各有 33 块多 TX 地形；候选无向 TX 对共 1149 / 1146 对，TX 距离中位数 18.03 / 18.38 m。表中只计筛选后有有效 RX 的地形/样本对。配对 RX 在地形和 TX 对内相关，不能视为独立实验次数。

再要求两次标签的附加衰减都>10 dB，方向仍不变。这类误差不能仅用所定义的几何可见/遮挡切换解释。当前模型确实没有恢复标签中已有的阴影变化，但这些变化中有多少来自可学习传播结构、有多少来自未公开生成细节，现有结果还不能分开。

## 5. 三种原因，证据分别支持到哪里

**地形与标签是否对不上：不支持整图粗错配；细观测对应尚未闭合。**

复用 CC 先前独立对应审计：25,720 张训练图、两个频段的最低有效 PL 都在标注 TX 的 3 m 内；原方向的地形可见性明显优于错地形、翻转和转置对照。原始索引定义、掩码位序和现有预测计分也已核查。这些证据反对普遍错行、错 TX 或整体翻转；不能证明每一个像素的生成坐标都正确。

本次完整官方验证上，区分 A<3 dB 与 A>10 dB 的平衡准确率：TX3 点位几何为 92.00% / 87.76%，TX2 敏感性几何为 96.11% / 95.29%。模型预测分区为 96.79% / 95.83%。点位几何与标签分区存在稳定差别；模型已补偿了一部分，但幅度仍不准。不能把这些分类数当成比赛 RMSE。

本次还检查了每块地形共用一个有效 TX 高度，以及 TX 高度取整假设。39 块原开发多 TX 地形用于发现，33 块不重合的训练多 TX 地形用于确认。每块地形用一半 TX 的标签选择假设参数，在另一半 TX 上检查。确认组：每地形常数高度的平衡准确率为 93.86% / 93.22%；一米取整相位假设为 94.01% / 92.90%。没有双频一致的额外优势，其他取整尺度也没有解决问题。此处只枚举几何假设，不训练模型；参数使用过标签，不能部署，也不能据此认定真实 TX 高度错误。先前近场检查也不支持简单把真实高度从 3 m 改成 2 m。

原始 metadata 说明：RX 是地形网格向上平移 1 m 的三角单元，单元中心结果再经 griddata 映射到规则网格；不是直接对每个网格像素做点接收测量。Sionna RT 1.1.0 的 RadioMapSolver 定义是各路径功率的单元平均。因此，点位净空与标签之间本来就隔着单元积分和插值。它为细尺度差别提供了合理机制，但当前没有用原始单元值做前后对照，**不能说已证实插值造成了多少 dB**。[官方数据说明](https://raw.githubusercontent.com/lunarradiomapchallenge/lunarradiomapchallenge.github.io/main/dataset.html)；[Sionna RT 1.1.0 定义](https://raw.githubusercontent.com/NVlabs/sionna-rt/v1.1.0/src/sionna/rt/radio_map_solvers/radio_map_solver.py)。

**现有输入是否缺少决定性信息：有待核验的生成信息缺口，但尚未证明它主导误差。**

重新读取原始数组，找到 9 对完全相同的已提供地形和 TX 坐标。两频段的掩码逐对完全相同；标签配对差异的 pooled RMSE 只有 **0.020 / 0.067 dB**，逐对最大 RMSE 分别约 0.060 / 0.197 dB。共同有效像素分别为 586,059 / 514,756。这些样本没有显示几 dB 的同输入标签矛盾。

但重复坐标可能复用同一随机种子或同一仿真输出，不是已证明独立的随机重复。所以不能据此估计全局标签噪声下限，也不能证明输入完整。验证集中没有相同输入重复，相关配对 RMSE 记为未定义。

本次使用的发布层文件没有原始射线追踪场景网格、实际连续 TX 三维坐标、插值前逐单元功率、逐次随机种子输出。它们是继续分离原因所需的诊断资料；不等于最终模型必须把这些都作为输入。没有真实 CSI/PDP/PAS，本身也不能证明高度图与 TX 不足以预测路径损耗。RadioMapSolver 的功率定义同样不支持把未解释残差直接归为未知相干相位。

**模型是否没学会：当前预测未拟合的现象已经证实，具体原因尚未独立区分。**

训练内误差很高；同地形深遮挡下，TX 变化与双频变化幅度均偏小；稳定可见区则已低于 1 dB。这些都是当前冻结模型的失效证据。没有做新的容量、优化或结构消融，所以不能指定“加大模型”“延长训练”或“再加一个特征”必然解决。

## 6. 数值与数据核查

固定随机 128 张验证图，关闭 autocast 和 TF32 做严格 FP32 前向。415 MHz 分数从 3.650784 变为 3.650922 dB；5.8 GHz 从 4.509427 变为 4.510080 dB。变化小于 0.001 dB。推理精度不是主差距；这不检验训练精度对最终权重的长期影响。

全部主分数使用原始有效掩码，NumPy float64 累计。官方验证有效像素为 151,537,682 / 135,926,253；训练匹配组为 151,646,491 / 139,193,476。主分区 SSE 与总 SSE 闭合；细分六区逐像素互斥且完整。严格可见区不是全部可见像素，不能将其 0.62 / 0.75 dB 外推到全图。

冻结检查点 SHA256：4355f5e831aa280bf502c01488f823d67eee389e769e8d616644fa9d9a9ca907。GPU 只使用实体 3：GPU-9a72820b-a8c2-0a94-2297-4f65afc67eb0。两个冻结推理任务合计约 72.5 秒（含输入几何及输出），没有更新权重。

本轮已经将官方验证标签用于事后诊断。没有据此改变模型或发布新分数。今后若据这些发现选模型，需要明确这次接触记录，不能再称官方验证完全未被查看。

## 7. 下一步的证据条件

先取得一小批完整的原始生成记录：同一地形的实际场景网格与 TX 三维坐标、插值前单元值、最终网格值，以及独立随机种子的重复输出。逐步对照可分别检查：（1）输入高度图到真实场景是否一致；（2）单元到网格是否引入状态偏移；（3）固定场景的随机重复误差是否接近当前残差。这是缺少的定因证据。现有文件不能替代它们。

在这些信息未补齐前，不能把原因定死为“数据有错”或“信息不够”，也不能承诺靠新模型达到 1 dB。本轮完成冻结诊断后停下，不继续训练。
