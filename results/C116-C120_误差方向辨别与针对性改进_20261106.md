# C116–C120：误差方向辨别与针对性改进

本轮仍未做出大幅提分版本。相同484块内部确认地形上，最好候选为2.294224 / 2.581297 dB，比C82改善0.009576 / 0.015358 dB。未通过双频各0.30 dB的扩训门槛。正式C82的官方固定验证仍为2.246377 / 2.579150 dB，官方综合2.412764 dB；本轮没有新的官方分数或提交。

这轮把失败模式进一步定位为：当前表征能找到误差高发区域，但难以辨别其中每个像素需要正向还是反向修正。它不等于证明原始输入缺少信息，也不能作为1 dB不可达的证据。

## 数据与评价范围

全部实现、缓存、训练与分析在CC。只读取父目录data顶层发布的TRAIN原始文件，没有读取或复用CC外其他AI的代码、模型或特征。没有重启C95接收面数值偏移方向。

沿用1984块FIT地形的2815张图。C116和C120用既有每图1536个训练位置；C117–C119用全部有效原生像素。原128块监测地形含628张图。原484块确认地形含1934张图，每图固定2048个位置，双频有效像素数为3,930,241 / 3,587,418。这个内部留出面板已用于历史研究，不称全新盲测。

各候选只按128块监测地形选检查点，选择冻结后再确认。掩码用于损失、评价和C120明确标注的离线条件筛选，不作为网络输入。官方VAL标签没有用于本轮开发。内部开发C82与正式全TRAIN重拟合C82不是同一套权重，不能混用两者的分数。

## 1. 先排查两个可能修复的前提

C82在训练抽样上的RMSE为2.185366 / 2.468844 dB，在监测抽样上为2.140018 / 2.411312 dB。C72见过和没见过的FIT地图分别为2.163485 / 2.451169与2.203427 / 2.483465 dB。正残差尾部比例也接近。这不支持存在很大的总体残差分布偏移，但没有排除更细的条件分布差异。

在每个监测位置的9×9邻域内，即行列各±4像素，借助真实标签挑选最合适的C82双频共同位移，RMSE仍为1.199164 / 1.448569 dB。在C82漏掉的弱点中，73.04% / 71.54%的真实功率仍比邻域内全部候选预测都弱超过1 dB。

这个位置选择使用了真实标签，只用于判断修改空间。它说明只搬动C82现有局部结构仍缺少许多衰落幅度，不能当成可提交预测，也不是其他模型的误差下限。

证据：audit/c116_targeted/diagnosis.json。

## 2. 实际完成的修改和确认结果

下表均为同一484地形、1934图、每图2048点。单位dB，顺序为415 MHz / 5.775 GHz。

| 候选 | 具体修改 | 确认RMSE | 相对C82改善 |
|---|---|---|---|
| C82 | 冻结基线 | 2.303800 / 2.596654 | — |
| C116 | 对169个既有精细输入使用深度10的阈值树残差读出 | 2.295919 / 2.593872 | 0.007881 / 0.002782 |
| C117 early | 地形与TX从编码器第一层混合 | 2.303557 / 2.595700 | 0.000243 / 0.000954 |
| C117 factorized | 先编码地形，再以TX特征、接收点特征和乘性交互解码 | 2.302383 / 2.594933 | 0.001417 / 0.001721 |
| C118 plain | 从共同父模型继续普通功率误差训练 | 2.295959 / 2.582948 | 0.007841 / 0.013706 |
| C118 location | 加入原生像素正/常规/负残差的分类监督 | 2.297378 / 2.588354 | 0.006422 / 0.008300 |
| C119 plain | 从C118 location继续普通功率误差训练 | 2.294224 / 2.581297 | 0.009576 / 0.015358 |
| C119 endpoint / pair | 端点加权 / 相邻相反误差对比；均选回父模型 | 2.297378 / 2.588354 | 0.006422 / 0.008300 |

C117两组均为2,263,698参数，初始参数完全相同，输出头清零，初始预测精确等于C82。地形编码器保留原生分辨率跳连。factorized组对相同H、不同TX条件的地形编码逐值一致；early组不一致。两组用同样的数据、样本顺序、学习率和最大8轮预算。按共同耐心规则，early在第6轮结束、选第3轮；factorized完成8轮、选第8轮。最终检查点不是等步数容量比较；匹配前缀轨迹另存。

C118从同一个C117父权重出发，增加相同的分类头。唯一损失差异是是否加入0.25倍类平衡交叉熵。分类头在推理时不提供标签。两组都完成8轮；plain选第6轮，location选第8轮。定位监督确实改变了表征，但没有优于普通功率训练。

C119以C118 location为共同父模型，三组都取消分类辅助损失。对照包括普通MSE、相同困难端点加权MSE、相邻正负残差差值MSE。后两组的端点和权重相同，只差交叉项。每个正残差点与5×5邻域内负残差点配对，辅助系数固定0.02，不用验证集调系数。

这类配对端点在监测抽样中占平方误差35.85% / 35.31%，因此有值得测试的误差规模。但相同4轮时，pair组监测RMSE为2.175756 / 2.448349，普通组为2.137798 / 2.406782。pair组反而更差。endpoint和pair都按监测规则选回第0步父模型；表中回退分数不是训练末端分数。三组没有扩训。

## 3. 为什么定位改善没有转化为大幅提分

这里“正残差”指真实路损比C82高至少5 dB，需要降低预测功率；“负残差”指真实路损比C82低至少5 dB，需要提高预测功率。

C118 location在原128地形的固定抽样位置上，对绝对大误差的平均精确率AP为0.4225 / 0.4285，明显高于大误差占比3.76% / 4.54%。它已经学到哪些位置容易出问题。

但在其预测弱点概率最高的1%位置中：

| 条件 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| 实际需要降低功率的比例 | 24.02% | 27.07% |
| 实际需要提高功率的比例 | 28.26% | 33.61% |
| 实际残差RMS | 8.168 dB | 9.237 dB |
| 实际平均残差 | 0.360 dB | 0.376 dB |

这些区域中，误差幅度很大，但相反方向混在一起。只知道“容易出错”，还不足以知道每个像素该往哪个方向改。对整个区域统一加深衰落会伤害相反方向的点；回归均值则倾向于输出很小的修正。这是当前已学习表征的具体失败，不能外推为所有可能表征都无法辨别。

证据：audit/c118_location/location_probe.json。

## 4. C120：把连续功率回归换成更简单的方向判断

为了检查是否仅是功率回归头没学好，额外做了专门的二分类任务。先用真实标签筛出已经发生绝对误差至少5 dB的位置，再只判断残差正负。这个筛选是离线真值辅助条件，部署时并不知道，不能把下表当成参赛性能。

对照A只使用169个既有H/TX/C82输入；对照B另加96维C118原生空间特征。相同树深9、相同最大2000棵树、相同学习率和早停规则；两频段分别训练。只在原128监测地形检查，没有再使用484确认集选择这个诊断。

| 原128地形上的条件方向判断 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| 始终猜多数方向 | 61.42% | 59.38% |
| 169个既有输入 | 67.64% | 63.99% |
| 加入96维空间特征 | 69.57% | 67.17% |
| 空间特征带来的改善 | 1.93个百分点 | 3.19个百分点 |

双频条件样本数为47,962 / 53,681。新增空间特征包含一些可迁移的信号，但连这个更有利、更简单的任务也仍有约三分之一方向判断错误。没有通过预先规定的双频准确率至少80%、比旧输入增加8个百分点及对数损失下降0.05的后续解码门槛。因此没有继续扩训。

证据：audit/c120_sign/summary.json。不能用69.57% / 67.17%声称原始输入的最佳可能准确率就是这个值。

## 5. 能确定与不能确定的事

能确定：本次阈值读出、地形/TX分离、原生弱点监督和相邻误差对比都未形成大幅提分版本。新表征对高风险区域的识别强于对精确误差方向的识别。具体像素的传播状态辨别是当前模型的关键缺口。

不能确定：这个缺口究竟来自公开输入未记录的细尺度状态，还是仍未提取的H/TX信息。小集能记住、局部表征或这几个架构失败，都不能证明输入不可约下限。没有依据保证继续增大模型或延长这些训练会达到双频1 dB。

不把微小的统计显著改善当作大幅提分。C116–C119均未通过双频各0.30 dB门槛，没有全TRAIN扩训、融合权重调参、官方VAL开发或网站提交。
