# 地形、标签对应与同一传播状态内误差诊断
2026-10-31。全部新增工作在服务器 CC 完成。只读发布的 train 数据与 CC 已有检查点。没有训练、优化器、反向传播、新传播仿真或新增传播训练标签。没有读取另一 AI 的工程代码、特征、模型或结果。GPU 只用于两次冻结权重前向，均锁定实体 3 的完整 UUID。

结论：已经定位到两类主要失配。第一，按高度图点位定义的传播状态，与发布标签的实际衰减分区并不完全一致。第二，在 TX 和 RX 前后都处于深遮挡时，模型仍明显低估随 TX 改变的附加衰减变化。几何版没有解决第二个问题。不能把当前问题归结为训练轮数不足、统一坐标错位、计算精度，或少量孤立像素。

还没有完全定因的是第一类失配的生成环节，以及第二类变化中可学习物理结构与仿真/插值变化各占多少。现有数据不足以把这些量分离。以下结果不证明已经找到能达到双频 1 dB 的方法。所有分数都是内部开发诊断，不是官方固定验证成绩。

## 1. 数据对应关系：粗配准正确，细节对应仍有缺口

- 核查全部 25,720 张 train 图。两个频段每一张图的最低有效路径损耗像素，都位于标注 TX 的 3 米范围内。没有发现整图错行、TX 对错样本、整体翻转或行列交换的证据。
- 另选 128 块不同的开发地形，每块一张 TX 图。前 64 块用于发现，后 64 块用于确认。几何检验的“低衰减/强衰减”来自标签归一化后的功率代理，不能当作真实路径 LOS 标签。
- 固定参考：TX 高度 3 米，RX 高度 1 米，沿线双线性地形采样。E 为地形高出 TX—RX 直线的最大高度。E < -0.25 米为几何可见，|E| ≤ 0.25 米为临界，E > 0.25 米为几何遮挡。

| 假设 | 发现组平衡准确率 | 确认组平衡准确率 |
|---|---:|---:|
| 原方向，TX 3 米 | 87.32% | 89.12% |
| 错地形对照 | 52.54% | 54.23% |
| TX 2 米敏感性假设 | 95.38% | 96.10% |

原方向显著优于翻转、转置和错地形对照。TX 2 米假设在不同标签衰减阈值、不同 TX 局部坡度组中，都更贴近衰减分区。已检查地形偏移、TX/RX 半像素位置、两种三角面插值、接收单元角点范围和接收高度。这些固定候选没有消除差别。首次接收面交点与表面正反面假设也不如原几何或 2 米敏感性假设。

但不能据此把真实 TX 高度改成 2 米。独立的近场检查使用 248 块训练地形的 413 个平坦 TX 邻域。靠近 TX 的像素，3 米假设的标签减参考值均值约 -0.39 / -0.35 dB；2 米假设约 +4.00 / +4.04 dB。有限接收单元与插值会影响近场值，因此这只是对“统一改成 2 米”的反证，不是精确高度反演。

官方说明仍为 TX 3 米、RX 地形网格上移 1 米。标签来自接收三角单元，再插值到规则网格。Sionna 的单元值是单元平均功率。因此，把它直接视为精确像素点接收机，属于观测近似。[官方数据说明](https://raw.githubusercontent.com/lunarradiomapchallenge/lunarradiomapchallenge.github.io/main/dataset.html)；[Sionna RT 1.1.0 定义](https://raw.githubusercontent.com/NVlabs/sionna-rt/v1.1.0/src/sionna/rt/radio_map_solvers/radio_map_solver.py)。

发布文件中没有对应的原始三角网格、未插值单元值、逐路径数据或独立重复仿真结果。当前无法确认差别来自哪个生成步骤。没有修改 metadata，也没有把 2 米分区当作真实 LOS。

在完整开发抽样中，用相同 384 点采样比较 TX 3 米和 2 米敏感性假设，原“几何可见”区中改变分区的像素占全部有效像素的 9.21% / 9.97%。这部分像素贡献 23.11% / 31.33% 总平方误差。这不是已消除的误差，而是原先“同一传播状态”定义混入了几何敏感区的证据。

## 2. 同一深遮挡状态内，模型没有跟上 TX 改变引起的衰减变化

使用同一地形内实际存在的不同 TX 标签，不生成反事实标签。固定接收位置。先扣除按实际距离计算的自由空间参考，再比较附加衰减变化。只有两个 TX 条件下都满足 E > 2 米的像素进入“深遮挡”组。此阈值只用于诊断。

匹配比较包含 39 块开发地形、273 对邻近 TX；TX 距离中位数为 45.80 米。B0 与 B1 使用完全相同的样本对和像素。

| 深遮挡下的 TX 变化 | 415 MHz | 5.8 GHz |
|---|---:|---:|
| 标签变化的标准差 | 6.701 dB | 7.220 dB |
| B0 预测变化的标准差 | 1.904 dB | 4.200 dB |
| B1 预测变化的标准差 | 1.687 dB | 4.109 dB |
| B0 变化预测 RMSE | 6.514 dB | 5.382 dB |
| B1 变化预测 RMSE | 6.428 dB | 5.539 dB |

415 MHz 的配对有效像素为 5,873 个，5.8 GHz 为 1,173 个。样本对和像素存在相关性，不能按独立样本解释。B1 的变化相关系数为 0.285 / 0.651。几何版主要输入相对位置、距离和高差，仍然没有恢复阴影内部随 TX 改变的幅度变化。低频表现尤为明显。

在 B0 的全部 39 块多 TX 开发地形上，使用更密的 1,366 对邻近 TX，深遮挡标签变化标准差为 5.95 / 5.84 dB，预测只有 1.45 / 2.14 dB。匹配比较与完整多 TX 分析方向一致。

这支持把研究对象转向“具体 TX—地形—RX 关系如何改变阴影内的附加衰减”。它没有证明所有未学到的变化都可由现有输入预测。原始路径与独立重复标签缺失，暂时不能把散射、反射、透射、插值和采样变化逐项定量归因。

## 3. 模型错误不只是阴影边界

对全部 2,562 张开发图，每图使用预先固定的 1,024 个接收位置。令 A = 路径损耗减自由空间参考。以 A < 3 dB、3 ≤ A < 10 dB、A ≥ 10 dB 分成低、中、高衰减三类。它们是标签/预测的功率类别，不是真实传播机制标签。

| B0 标签与预测的关系 | 415 MHz 平方误差份额 | 5.8 GHz 平方误差份额 |
|---|---:|---:|
| 衰减类别不一致 | 52.24% | 63.40% |
| 同为高衰减，但强度仍不准 | 44.12% | 34.26% |
| 同为低衰减 | 3.40% | 2.25% |
| 同为中衰减 | 0.25% | 0.09% |

同为低衰减时，B0 RMSE 为 1.084 / 1.173 dB。同为高衰减时，仍为 7.091 / 10.255 dB。不能只修正类别或边界。即使两个几何高度假设都判为遮挡，B0 RMSE 仍为 6.430 / 7.085 dB。几何版在匹配抽样上的类别错配平方误差份额仍为 53.15% / 63.32%。

完整像素的 512 张开发图中，把残差投影为每个 8×8 块内的有效像素平均值，仍保留 B0 总平方误差的 55.46% / 66.71%。B1 为 53.26% / 64.72%。因此，大量误差是成片的偏差。这个分解是描述性的“真值平均偏差”，不是已经能执行的修正。空间相关性本身也不能证明这些误差都可学习。

孤立衰减点确实存在。几何强可见区中，标签高于参考 6 dB、但 9×9 邻域至少 75% 有效像素低于参考 3 dB 的点，只占总平方误差的 4.58% / 2.53%。不能用这一小类点解释主要误差，也不能直接把它们当成随机噪声或误差下限。四个原始标签、剖面和误差图已人工查看，保存在同一审计目录。

## 4. 排除几条小修补作为主路线

冻结检查点为 B0 第 60 轮、B1 第 35 轮。这是当前检查点的失效诊断，不是模型表示能力的上限测试。各取 512 张训练图与 512 张开发图。两组多 TX/单 TX 数量匹配，地形不重叠。按原始有效像素掩码、float64 累计计算。

| 模型 | 训练样本 415 / 5.8 | 开发样本 415 / 5.8 |
|---|---:|---:|
| B0 基线 | 4.718 / 6.368 dB | 4.811 / 6.702 dB |
| B1 几何版 | 4.576 / 6.180 dB | 4.634 / 6.363 dB |

训练内误差已经很高，不能把主要差距归因于留出地形泛化。该检查没有区分模型容量、优化状态与不可预测标签变化，也没有证明继续训练绝不可能改善。它说明单靠延长原路线训练，当前没有充分依据。

- 全精度前向替代 BF16，开发 RMSE 改变均小于 0.01 dB。不能用推理精度解释主差距。它不检验 BF16 训练对最终权重的长期影响。
- 8 种旋转/翻转对齐后取平均：B1 开发 RMSE 从 4.634 / 6.363 降到 4.499 / 6.073 dB。地形重采样的增益 95% 区间为 0.102–0.171 / 0.224–0.361 dB。收益真实但幅度小，且需要额外前向计算。
- 仅在严格几何可见区限制过大的预测衰减，固定规则在确认组只改善约 0.014 / 0.020 dB。没有继续搜索更多后处理阈值。
- 2 米几何假设只用于敏感性分析。没有将其换入模型，也没有“2 米模型得到更好 RMSE”的实验。

## 5. 有依据的解决方向及尚未满足的条件

应先解决观测对应，再以完整传播几何为条件预测附加衰减。这是下一条值得验证的路线，不是已经验证成功的模型。

1. 保留官方 TX 3 米 / RX 1 米定义。把点位可见性、接收单元范围和相邻几何假设的分歧单独输出。先用它识别几何敏感区，不把单一 E 符号硬当成标签真实 LOS。原始网格和未插值单元值若无法取得，观测生成差别必须保留为未解决条件。
2. 以每个 RX 对应的有序 TX—RX 地形剖面，以及周围可见地形作为输入表示。保留障碍的位置、多个遮挡段、接收侧局部几何及邻近侧向地形。只加入最大 E、距离、平均坡度或整体起伏，不能表达这些排列和联系。剖面也不是完整的反射/散射路径；侧向地形不能省略。
3. 先扣除已知距离和频率项，分别处理衰减分区和阴影内的附加衰减。低频与高频共用几何条件，但保留各自的衰减输出。共享几何并不等于固定频差。仅把现有双输出重命名为共同项/差分项，不会凭空增加信息。
4. 后续若获得训练授权，优先用同地形多 TX 的真实样本对，检查模型是否能恢复“同为深遮挡时的变化”。同时检查错误衰减分区占比和阴影内 RMSE。若这三项没有明显改善，不应进入长训练或全量训练。阈值与对照需在运行前固定。

本轮没有启动这条训练路线。没有启动 B2、恢复 B1、完整训练或官方验证调参。官方固定验证 RMSE 尚未产出。当前不能承诺双频 1 dB，也没有证据宣布 1 dB 不可达。
