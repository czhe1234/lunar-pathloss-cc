# C21：网络架构审查与针对性对照方案

本轮只做代码、实验记录审查和候选设计。所有新文件位于 CC。没有训练新参赛模型，没有 GPU 计算。

**判断：针对性架构验证不足有直接依据。架构是否是剩余误差的主要原因，尚未由对照证明。下一步主线应转为受控网络架构对照，已有物理诊断用于结构设计与评价。**

C4 已有 8,985,986 个参数，其中全局 Transformer 为 2,367,744 个。已核对当前模型源码与完成运行记录中的 SHA256 一致。因此不能把全部失败概括为网络参数太少。需要具体检查信息怎样在网络中交互。

| 现有实现 | 能确认的限制 | 不能由此声称 |
|---|---|---|
| C10：294 维物理/地形特征＋双频独立树模型 | 没有学习完整地形场的空间表示；推理依赖预设特征组织 | 树模型一定弱于网络；新增网络一定提分 |
| C4：卷积 U-Net＋两层 Transformer | 全局交互位于 16×16 特征层；未显式编码 TX—地表—RX 的关系到注意力权重 | 米级信息全部丢失：原输入和高分辨率跳接仍然存在 |
| C15：同一特征集上的残差 MLP | 未检验从完整地形学习未被固定点特征保留的关系 | 已经排除端到端网络的收益 |
| C17：280,754 参数的 U-Net 残差修正 | 512 个 FIT 地形、128 个 DEV 地形、每地形一个 TX 的有限试验 | 代表大规模完整网络的能力上限 |

C15 的 FIT/DEV 为 2.715/2.963 dB 和 2.835/3.271 dB。C17 空间网络的 FIT/DEV 为 2.652/2.923 dB 和 2.891/3.481 dB。两者都仍有训练误差，也存在泛化差距。这些数来自各自的采样或试验子集，不是官方验证分数。不能只根据训练误差高就判定一定欠拟合，也不能只根据验证收益小就判定输入缺失。

C3/C4 等运行的初始化、输入组织、训练规模和学习率流程不同，尚未形成同数据、同预算的现代架构对照。C4 的训练日志是更新过程中聚合的训练代理指标，不能当成选定检查点在固定 FIT 集上的精确评价。

下一候选固定围绕三个问题设计：

1. **米级细节与远处地形如何直接交互。** 保留全分辨率局部支路，同时让 RX 查询读取多尺度地形表示。不能只在很粗的瓶颈层计算全局关系。
2. **传播方向和几何关系如何进入交互权重。** 将 TX→地表、地表→RX 的距离、方向、高差作为可学习的相对几何偏置。它们不是已知真实射线路径。
3. **同一地形怎样产生不同频段的细结构。** 共享地形编码，采用频率条件查询和频段独立的非线性读出。C19 的低跨频相关性只是这项对照的动机，不证明共享网络一定错误；原两通道输出也没有强制两频纹理相同。

该候选直接学习发布标签对应的双频附加路损。无需把尚不准确的 C20 解析点功率先修到正确，再允许端到端网络接受检验。观测过程的诊断结论保留，但不作为阻断网络能力对照的前置门槛。

**首轮比较只设两个可归因配置。**

- A：新多尺度骨干、局部细节分支、频率条件查询；采用内容注意力。
- B：与 A 相同，增加 TX—地表—RX 相对几何偏置。
- A/B 的输入信息、训练样本、样本顺序、优化器、更新次数和检查点规则一致。额外参数与计算量必须报告。
- 冻结 C10 作为性能锚点。A/B 与 C10 的特征组织不同，整体分数差不能单独归因于注意力；几何偏置的作用只看 B 对 A。
- 局部支路、频段读出、采样方式、附加损失的消融随后逐项进行。初轮不同时堆入梯度损失、频谱损失和难例加权。

初步统一输入为 H、TX 和相同的 45 个输入几何通道，即 C17 的前 45 通道，排除后两通道 C10 预测。实现前仍需逐通道核验。掩码只参与损失和计分。

优化先做小型 FIT 可拟合性检查，区分优化故障和明显的表达限制。拟合成功不代表学到物理，也不代表能够泛化到 1 dB。主对照使用既有按地形隔离的 FIT/DEV；固定更新预算，同时记录选定检查点的精确 FIT、DEV、遮挡边界、遮挡内部和双频差误差。初轮保持有效像素 MSE，使用官方均值 RMSE 公式与两频分项选验；官方 VAL 不参与调参。历史 DEV 已被使用的事实必须继续披露。

未来 GPU 工作仍只限实体 3 的完整 UUID。延续最近运行的 0.15 显存上限，按批传输数据，先测吞吐再定批量。高显存占用不等于网络能力充分，也不作为算力利用效率的证据。

本轮产物是可审查方案，候选尚未实现、未训练。当前官方版本仍是 C10，综合分 3.1775908266 dB。没有新分数，也没有证据保证新架构达到 1 dB。
