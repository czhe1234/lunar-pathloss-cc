# 网络架构与信息利用对照：C43–C46

本轮试验已完成并核对。结果支持“信息的组织方式影响学习效率”。有序剖面明显改善了新空间网络，但没有得到超过 C38 的双频版本。两个频段的官方验证 RMSE 均不高于 1 dB 的目标仍未达到。

## 相同信息，不同组织方式

C44 和 C45 使用相同的 128 个 TX–RX 剖面采样元组。每个元组含名义净空、经验性高度小数候选净空、沿线位置 t 和距离。C45 只用固定置换同时打乱元组顺序，保留数值及其原始 t 的对应关系。参数、初始权重、地图/像素顺序、批次和学习率轨迹相同。两组只比较前 1,000 步。

| 1,000 步时 | FIT 监测 RMSE，415 / 5.8 GHz（dB） | DEV 监测 RMSE（dB） |
|---|---:|---:|
| C44 有序剖面 | 4.370 / 4.664 | 5.078 / 6.511 |
| C45 打乱顺序 | 4.761 / 6.283 | 6.809 / 10.611 |

DEV 监测为固定 32 图、每图 8,192 个像素；两组均为 BF16。打乱后双频分别恶化 1.731 / 4.100 dB。500 步时差异很小，差异在后续学习中出现。这支持该设计在固定预算下的学习效率。只有一个训练随机种子；不能据此断言最终可达误差或恢复了真实传播路径。

## 完整内部验证

固定 DEV64 来自官方 TRAIN 内的地形隔离划分，含 64 块地形、264 张 TX 地图。415 MHz 有效像素为 17,190,967；5.775 GHz 为 16,005,803。以下完整面板结果均为全部有效像素、FP32 预测，禁用 TF32。

C43 使用高分辨率并行多尺度 CNN、稀疏跨注意力和双频 FSPL 残差输出。三组先在 64 块 FIT 地形训练 4,000 步，再分别从各自末权重扩展到 256 块 FIT 地形，继续 8,000 步。地图/像素顺序、损失和选步数规则相同。

| C43：256 块 FIT 地形 | 415 MHz RMSE（dB） | 5.8 GHz RMSE（dB） |
|---|---:|---:|
| CNN，无注意力 | 5.871 | 9.201 |
| CNN + 全局网格参考点稀疏注意力 | 6.311 | 10.011 |
| CNN + 路径引导参考点稀疏注意力 | 5.016 | 7.258 |

路径引导与网格参考点两组的参数和共有初始权重完全一致。路径引导改善 1.294 / 2.753 dB。按地形配对自助抽样 2,000 次，RMSE 差值 95% 区间为 [-1.819, -0.889] / [-3.945, -1.950] dB。区间不含训练随机种子的不确定性。CNN 跳过注意力，其有效参数量较少。

C44 在 C43 路径版上增加 128 点有序剖面卷积编码，增加 9,584 个参数。以下两组均使用 64 块 FIT 地形和相同的 4,000 步预算。

| 64 块 FIT 地形 | 完整 DEV64 RMSE，415 / 5.8 GHz（dB） | 16 张 FIT 监测图全像素 RMSE（dB） |
|---|---:|---:|
| C43 路径版 | 6.492 / 10.254 | 3.995 / 4.378 |
| C44 有序剖面版 | 4.578 / 5.631 | 3.599 / 3.312 |

C44 完整 DEV 改善 1.914 / 4.623 dB。这个对照同时增加密集剖面、卷积编码和高度小数候选，不能单独归因于顺序。顺序对照见 C45。

事先规定的扩展条件要求 DEV 和 FIT 监测图双频均改善至少 0.5 dB。低频 FIT 只改善 0.396 dB，未通过；没有启动 C44 的 256 块或全 FIT 训练。所选权重在训练监测图上仍有明显误差。

C38 在同一完整 DEV64 上为 **2.503 / 2.774 dB**。C38 使用全部 5,508 块内部 FIT 地形及 294 个显式物理描述量；新网络只用了 64/256 块地形及较基础的地形通道。这个性能锚点不能证明 MLP 普遍优于空间网络。

## 能否补上 C38 的剩余误差

C44 与 C38 的普通线性组合和双频交叉组合，均只做了同面板事后校准。双频交叉组合改善仅 0.000605 / 0.000062 dB；普通组合更小。收益不足，没有扩大确认。校准不是独立验证。

C46 固定内部 FIT 训练的 C38，将其双频预测加入输入。空间网络从 C44 特征权重启动，输出头清零，只学习（真实 PL − C38 预测）/20。物理几何和剖面只读原始地形通道。教师预测生产过程只读地形和 TX，不读标签或掩码。

C46 完成 1,000 步，批次 16，每图 2,048 个采样点，学习率 1e-4，保留 4,000 步学习率轨迹。实际曝光 16,000 次地图，配置中的 64,000 次规划曝光不是已完成量。运行总耗时 347.6 秒。

| C46 监测时点 | FIT RMSE，415 / 5.8 GHz（dB） | DEV RMSE（dB） |
|---|---:|---:|
| 0 步，即 C38 | 2.586 / 2.785 | 2.517 / 2.863 |
| 1,000 步 | 2.525 / 2.648 | 2.549 / 2.916 |

FIT 监测误差下降，但 DEV 分别恶化 0.032 / 0.053 dB。最佳检查点仍是 0 步。独立 CPU 核验确认：四个最终输出权重/偏置全零；264 张 DEV 图和 16 张 FIT 监测图的保存预测，与 C38 逐位一致。独立 FP64 计分重现 **2.503 / 2.774 dB**。无需对零修正权重重复 GPU 推理。

没有继续扩展，也没有执行剩余 548 块 DEV 确认或新增官方 VAL 评测。这个负结果限于当前 64 块地形、1,000 步和这一残差设计，不能排除其他非线性修正方法。

## 当前版本与结论边界

保留的最佳官方版本仍是 C38：**2.672718 / 3.080538 dB**。官方双频算术平均为 **2.876628 dB**。

各频段先累计全部有效像素平方误差与有效像素数，再开平方。官方固定 VAL 为每频段 2,330 图，有效像素分别为 151,537,682 / 135,926,253。官方计分脚本版本为 fa3ef9b89f964556753a18be102a5aadeb723377。

本轮新模型只用官方 TRAIN 内划分做梯度更新和检查点选择，没有新增官方 VAL 分数或网站提交。历史官方 VAL 曾用于版本计分和误差诊断，不能称为整个项目从未接触过的盲测集。原 C38 上传文件保持不变。

证据支持：保留剖面结构、让查询关注相关地形，能提高当前网络的学习效率。证据尚不支持：该组合超过 C38，或网络结构是达到 1 dB 的唯一障碍。本轮没有证明输入缺失形成不可约误差。数据不含逐路径复 CSI，不能声称提取了真实 PDP/PAS。

本轮有限试验已完成。结束这个分支不等于完成比赛目标。没有本轮后续训练队列。

## 实现、核验与来源

全部实现和实验位于 transformer:/home/chenzhe/work/lunar-pathloss-rm-challenge/CC，独立完成。GPU 只用实体 1 / 3 / 4，并按完整 UUID 限定。未终止其他任务。

设计参考 [HRNet](https://arxiv.org/abs/1908.07919) 的并行多尺度结构、[Deformable DETR](https://arxiv.org/abs/2010.04159) 的参考点稀疏注意力，以及[序列卷积研究](https://arxiv.org/abs/1803.01271)。本模型为自行组合的传播网络。剖面卷积是对称、分层实现，并非原样因果 TCN。

必要失败记录均保留：
- BF16 单图/批量差异由统一 FP32、禁 TF32 的最终推理解决。该差异不能解释多 dB 误差。
- C44 在 GPU1 因其他任务占显存提前中断；少于 40 步，精确步数未知，无检查点。有效训练在 GPU3 同种子重启。
- C44 首次独立推理错误导入 C43 类，未产生有效预测。修正后重新推理、独立计分。
