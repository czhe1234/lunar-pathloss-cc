# C108–C115：小集拟合后泛化失败的受限对照

本轮未获得可扩训的大幅提分版本。能确定：单纯增加新增残差监督地形数没有解决迁移；本次有序路径架构与TX高度派生对齐都没有双频收益。尚未把其他架构偏置与缺少未发布物理变量完全分开，不能声称已找到1dB信息下限。

## 范围与隔离

全部新增实现、训练、缓存与评价在CC。只读父目录data顶层原始TRAIN文件；没有参考其他AI的代码。所有GPU进程经run_gpu.sh按完整UUID限定实体1、3、4，设备身份记录于配置。没有系统修改、GPU重置、接收面数值偏移或C95方向重跑。官方VAL没有用于本轮训练、选型或诊断。

所有候选共同使用冻结C82基线和C99global第11轮特征初始化；该父模型以前已在5508块FIT地形上训练。因而本文“同地形新TX”及32块内部FIT地形，指本轮新增残差监督未用，不能称所有父模型未见。核对128个TX均曾在C99父模型训练中出现。真正未见地形仍看原128监测与484确认；C99父模型没有见原128监测。记录见parent_exposure.json。

原484地形确认固定为1934图、每图2048个相同位置，低/高频有效像素3,930,241 / 3,587,418。这个面板曾用于历史研究，不称全新盲测；它是内部抽样确认，不是官方VAL成绩。各项步骤和候选先冻结再确认。

## 1. 地形数量：固定更新与固定拟合程度两种对照

C108从277块有4个C82缓存TX的FIT地形中，按不读标签的固定随机顺序选择嵌套8/32/128块地形。每块3个TX训练、1个TX留给新增阶段。三组相同1215234参数、相同初始化、batch8、AdamW lr4e-4 wd.01、普通有效像素MSE，均4000更新；没有对标签尾部加权。

| C108固定4000更新 | 训练汇总RMSE | 原484确认RMSE |
|---|---|---|
| 8块地形、24张图 | 0.673 / 0.754 | 2.999 / 3.399 |
| 32块地形、96张图 | 1.195 / 1.354 | 2.869 / 3.199 |
| 128块地形、384张图 | 1.686 / 1.826 | 2.649 / 2.992 |

固定步数下，128组比8组确认改善0.351/0.407dB，但三组都比C82差。这一差异不能当作有效提分，也混入了不同的重复次数和拟合程度。

C110补充对照：三组都用最初8地形的相同24张训练图作为锚点，按其双频平均相对C82平方误差首次降至0.85停止，最多2000更新，停止不看留出。全部在同一A800上顺序执行。

| C110地形数 | 停止步数 | 锚点低/高频相对SSE | 原484确认RMSE |
|---|---:|---|---|
| 8 | 80 | 0.8759 / 0.8227 | 2.365 / 2.689 |
| 32 | 240 | 0.8744 / 0.8225 | 2.407 / 2.739 |
| 128 | 950 | 0.8787 / 0.8212 | 2.385 / 2.734 |

相同确认像素C82为2.304/2.597dB。训练拟合程度对齐后，128组没有优于8组，反而差0.020/0.045dB；按地形配对95%区间分别为[-0.0238,-0.0163]、[-0.0511,-0.0381]（8组RMSE减128组RMSE）。这不支持在本次范围内“只增加残差训练地形即可解决”。它不是对从零训练或完整FIT容量的普遍结论。

在同一地形、残差阶段未监督TX上，C110三组依次为2.113/2.550、2.133/2.566、2.135/2.594dB，相同C82为2.065/2.468。因此迁移失败在改变地形前已出现；但该TX对照只隔离新增残差阶段，不能忽略父模型曝光。

## 2. 架构与输入派生的一致性

C109用同一128地形384图、同输入、同参数1220994、同初始权重及相同2000更新，对照有序TX→RX剖面和固定打乱剖面。32步剖面包含H/TX导出的相对高度、Fresnel尺度、坡度、已有C82超额、位置和距离。打乱时保留全部点与位置通道，只改变局部卷积看到的邻接顺序。没有增加原始数据。

| C109 | 原484确认RMSE |
|---|---|
| 有序剖面 | 2.510 / 2.876 |
| 固定乱序 | 2.495 / 2.869 |

有序组没有胜出，低/高频反而差0.0146/0.0077dB，配对区间均不支持有序优势。这只否定了本次局部路径读取方案，不能否定所有架构或证明输入缺信息。

C114另外隔离输入派生约定：旧基础输入用H[row,col]+3，C82谱读出距离用floor(H[row+1,col])+3。这384张训练图上两者平均绝对差0.532m。保持原网络、参数、初始化、采样和2000更新，仅同步改5个关联输入通道；其余53通道及C82基线不变。试跑逐通道检查、基线和标签掩码相等检查通过。

| C114 | 原484确认RMSE |
|---|---|
| 旧约定 | 2.497 / 2.856 |
| 与C82谱读出约定一致 | 2.491 / 2.866 |

低频略好、高频略差，没有双频提分。这个对照是已有特征定义的一致性检查，不是证明官方真实TX高度，也不涉及重新找原始网格或接收面数值偏移。

上述所有网络的原128监测最佳均为第0步，即不修正C82。因此确认表中的训练末端是诊断数据，不能冒充选出的新最优模型。所有分支均未晋级。

## 3. 原始输入重复与标签随机波动

逐字节哈希全部6120张发布地形，结合整数TX坐标，检查25720条TRAIN记录。找到9组相同H/TX、共18张图。重复组大部分标签完全一致；仅这些重复矛盾对应的组内最小RMSE约0.010/0.033dB。它给出的全TRAIN必有误差下界约0.000263/0.000869dB。

这个很小的下界不等于真实信息下限很小，也不是误差上界。它只说明这些重复记录未表现出足以解释当前2–3dB的逐次随机差异。相同H复用同一未发布场景时，仍不能排除隐藏网格、接收单元等场景状态；需要独立改变或观测那些变量才能辨识。

## 4. 米级TX变化到底是什么

C111仅在FIT中按元数据选择水平TX坐标相差1m的39对样本，涉及37块地形；接收点距两TX均至少10m。低/高频2520905 / 2288122个共同有效配对位置上，标签变化RMSE为3.997/5.613dB；逐对中位数为2.164/2.825dB，说明汇总受长尾影响。约5.77%/5.91%的位置变化超过5dB。

“1m”指水平网格位移，不保证三维TX位置只变1m。39对中35对的C82派生TX高度相同；这35对仍有2.731/3.738dB标签变化。另4对派生高度变化1m，标签变化更大，不能把混合汇总都归因于纯水平敏感度。

C112用原始H/TX重新前向冻结的开发C82（没有新训练）。先在4张已有缓存图上重放核验，像素RMS差0.00436/0.00499dB，通过预设0.03门槛；再生成94张输入纯净预测。预测阶段不打开原始PL或mask文件。随后CPU分别读标签做独立评分。

| 所有39对水平1m样本 | 415MHz | 5.775GHz |
|---|---:|---:|
| 标签变化RMSE | 3.997 | 5.613 |
| C82预测变化RMSE | 3.408 | 4.888 |
| 变化量预测误差RMSE | 2.098 | 2.504 |
| 相对“零变化”解释的变化能量 | 72.44% | 80.10% |
| 配对当前误差中的共同分量 | 77.76% | 75.72% |

共同/差分分解逐像素满足((e1^2+e2^2)/2)=((e1+e2)/2)^2+((e1-e2)/2)^2，非学习拟合。35对同派生TX高度子集的变化能量解释率为51.69%/62.23%，显示高度变化的4对显著影响总体解释率。C82已捕捉很多响应，但仍漏掉部分敏感位置；不能简单写成完全不响应TX。

## 5. 新表征是否有可测预测价值

C108双频离线参考：给定同位置另一频段的真实残差时，确认共同有效像素上的RMSE由2.151/2.577降到1.562/1.871；打乱位置或只给整图均值几乎无益。这说明有位置相关的双频共同成分，但用了真实另一频段标签，不是可提交结果，也未达到1dB。

C111同地形TX覆盖检查：原始多TX地形各有51条记录，近期C99整图训练每块只用8个TX；这不代表C82的其他组成部分没用过其余记录。已知3/8/40张TRAIN功率图，预测另一个TX，query及相同坐标的重复记录不作为供体。40供体的最近TX距离中位数仍约19.9m；40供体的FSPL超额插值仍为6.468/10.145dB，相同有效位置C82为2.197/2.449dB，不能把更多TX功率图的简单空间插值当成解决办法。供体掩码只表示已知观测有效性，评价统一在query有效且原3供体至少一张有效的位置。该对照不能直接用于没有已知功率图的新地形。

C113同地形局部状态参考：已知3个TX的真实C82残差，按接收点均值、角向核或最近方向转移到另一个TX；在128块FIT地形校准，再到32块内部FIT地形评价。在额外给出3张真实残差图后，均值/角向方法也只改善约0.001–0.003dB。它不支持粗粒度的“地形固定偏差图”或简单角向插值是可用解法。该参考同样不是可提交的新地形预测。

C115检验仅由H/TX和两次C82前向可得的TX敏感度：原输入点值、RX空间梯度与H/TX为基线，新增有限TX差分、方向导数和交互项。用37块FIT地形逐地形LOTO岭回归，所有同地形样本一起留出。C82为2.2244/2.5405，基线读出2.2251/2.5419，敏感度读出2.2258/2.5421。没有可扩训收益，只否定这个线性探针，不代表所有非线性敏感度表征无效。若未来采用双查询，还需单独验证推理时间。

## 判断与未解决部分

有证据的直接失败模式：新增残差网络能拟合具体地形与TX组合，却没有建立能迁移的局部功率结构映射。该结构可重复、与具体接收位置和TX条件有关；不能用整图偏置、粗跨TX平滑或独立随机噪声概括。

训练地形数量在本次范围内不是一个已经验证的单独解法。有序路径读取与统一已有高度派生也未构成有效新架构。原始输入是否缺少决定细结构的变量仍未识别；当前数据中未独立控制未发布的网格/接收面状态，有限观测既可能由复杂H/TX函数解释，也可能依赖隐藏物理状态。不能用失败的模型家族证明信息缺失，也不能从有限小集拟合成功证明输入对新地形充分。

本轮没有满足相同确认面板双频各改善至少0.30dB及正配对区间的候选。不全TRAIN扩训，不调融合，不提交新版本。官方固定VAL仍为C82：2.246377/2.579150dB，综合2.412764dB；双频1dB目标未完成。
