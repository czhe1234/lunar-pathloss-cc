## 1. 结论与决策

用户提出的主假设值得保留：显式计算“TX 照亮哪些地表、功率怎样沿路径传递、最终怎样进入接收单元”，并让同一地形的多个 TX 共用传输规则。这与给普通回归器增加几个物理特征不同。

但首轮实际检验发现一个必须处理的接口约束：

**如果把现有候选几何算出的直达功率 D 固定，再要求其他分支只增加非负功率，则这个模型族在原 128 地形留出集上，即使借助真值完美补足其他功率，RMSE 仍不低于 2.083 / 2.320 dB。它达不到双频 1 dB，也达不到本轮的初筛提升门槛。**

这句话的条件不能删除。它针对当前候选网格、TX、接收面、发布映射与直达计算的组合。它不证明原始输入缺少信息，不证明所有传播模型都失败，也不证明 1 dB 不可能。

独立检查还发现：同一候选几何上的官方 Sionna Radio Map 与自建面积求积，确实给出不同的细尺度直达功率。但把这份差异直接用于修正 C82，在预先选定的 8 张训练留出图上反而变差。因此，本轮没有找到可直接带来明显提分的数值修复。

**本轮决策：保留共享传播算子的研究假设；不采用“固定现有 D 后只补正功率”的实现；不扩大测量差修正实验；不启动完整网络扩训。** 后续原型必须允许共同校准有效受照覆盖与接收测量，并用对照检验校准是否真的跨地形有效。这个修改还没有经过学习实验。

## 2. 题目、数据和分数口径

任务输入是 256×256 地形高度图和 TX 像素位置。输出是 415 MHz、5.775 GHz 两个频段的正路损图。路损定义为 y = −10 log10(G)，G 是无量纲线性路径增益。数值越低表示功率越强。

发布 metadata 说明：数据由 Sionna RT 1.1.0 生成；TX 高度为地面上 3 m；接收网格是地表网格沿 z 方向平移 1 m 的副本；包含直达、镜面反射、漫散射和折射，不包含绕射。数据发布还涉及三角单元采样、插值、翻转、多随机种子平均和缺失填补。原始网格、精确 TX 坐标及完整导出代码尚未拿到，不能把当前重建约定说成原始真值。

评分按每个频段的所有有效像素累计平方误差，再除以有效像素数并开方。不是先算每张图 RMSE 再平均。5.8 GHz 的静态填充值由有效掩码排除。训练、留出集、官方固定验证集按地形隔离。

## 3. 原方案中必须明确的物理含义

### 3.1 线性功率累计正确，但不能忽略观测过程

Sionna Radio Map 对接收单元做面积平均，并非相干地累计不同路径的功率。因此，先计算线性增益，再转成 dB，是正确的物理方向。接收单元面积积分和最终发布像素之间仍隔着导出与插值过程。[Sionna Radio Map 技术说明](https://nvlabs.github.io/sionna/rt/tech-report/S4.html)

“求出了物理单元平均值”不自动等于“复现了发布标签”。本轮仍冻结旧候选几何和映射，没有搜索 TX 偏移、网格拓扑或像素平移，没有重启 C95。

### 3.2 官方漫散射是 Lambertian

发布 metadata 指定 lambertian。Sionna RT 1.1.0 对应角分布为 abs(ko_local.z)/π，不以入射方向 ki 改变漫散射角分布的形状。入射方向仍影响入射功率、Fresnel 系数、极化和被照射的面侧。[固定版本源代码](https://raw.githubusercontent.com/NVlabs/sionna-rt/v1.1.0/src/sionna/rt/radio_materials/scattering_pattern.py)

因此，不能把“漫散射后必须长期保存任意入射方向记忆”当作已确认的缺失物理。连续方向最明确的价值在镜面、折射、路径可见性和接收覆盖。方向状态与极化状态也不能混为一谈。非相干路径累计不取消单条路径上的极化作用。[Sionna 材料与极化说明](https://nvlabs.github.io/sionna/rt/tech-report/A1.html)

### 3.3 路径分工必须完整且互斥

建议按“路径中是否出现过漫散射事件”划分：

- 无漫散射路径：直达，以及纯镜面／折射路径。
- 至少一次漫散射的路径：Q 负责到第一次漫散射，K 负责两次漫散射事件之间的传递，A 负责最后一次漫散射到接收测量。

Q、K、A 的中间路径可以包含镜面或折射段。只做“纯镜面单独一支，加纯漫散射若干跳”，会遗漏混合路径。若同一路径同时进入两支，则会重复计算。这个划分来自求解器的路径结构，不是本轮已经验证的提分机制。[Sionna Radio Map 路径分解](https://nvlabs.github.io/sionna/rt/tech-report/S4.html)

### 3.4 与旧工作的差别不能只写成“加入多跳”

CC 的 C92 已有原生三角面上的多次双侧漫散射。C91 已做连续单次镜面候选，C79 已在候选几何上运行官方完整传播机制。C124 使用角度／时延功率分箱作为预测特征；C127 的多 TX 训练没有强制复用一个物理传输算子。

新方案的实质增量应当是：跨 TX 共用可训练的传播规则，功率状态实际沿路径更新，最终通过明确的接收测量得到输出。仅把物理量拼接后回归路损残差，不算实现这一点。

## 4. 固定直达功率的模型族检验

### 4.1 为什么可以在训练前检验

假设模型固定 D，并输出：

Ghat = D + R，R ≥ 0。

因此，预测路损一定满足 yhat ≤ −10 log10(D)。即使让 R 逐像素读取真值，最好的预测也只是：

yoracle = min(y, −10 log10(D))。

无法消除的误差为：

efloor = max(y + 10 log10(D), 0)。

D = 0 时不施加有限路损上界。此处使用标签只是计算受限模型族的理想下限；不是可提交预测，也没有将标签放进物理前向。

这个检验对后续反射和散射分支极其有利：它们不受容量、物理可实现性或训练难度限制，允许任意非负补足。如果这个理想版本仍达不到目标，扩大这些分支就不能解决该实现的障碍。

### 4.2 实现与面积求积收敛

沿用 CC 既有候选三角网格、TX 高度、RX 网格和三角单元到像素的映射。每张图有 130,050 个候选三角面。物理计算只使用 H/TX；标签与掩码在物理前向结束后用于计分。

| 每三角单元求积点数 | 固定无遮挡直达 D 的理想下限：415 | 5.775 |
|---:|---:|---:|
| 1 | 2.052943 | 2.227378 |
| 4 | 2.073218 | 2.286650 |
| 16 | 2.080001 | 2.310125 |
| 64 | 2.082055 | 2.317641 |
| 256 | **2.082546** | **2.319596** |

单位 dB；范围为原 128 地形、628 图。64→256 点的变化为 0.000491 / 0.001955 dB。在该几何和映射下，继续增加求积点不能解释双频 1 dB 的差距。

若把原材料模型的直穿透射也固定加入 D，256 点下限进一步变为 2.547976 / 2.319596 dB。这里主结论采用更宽松的“仅无遮挡直达”版本。

与同集 C82 相比，理想补功率的最大可见改变量只有约 0.064 / 0.098 dB，低于双频各 0.20 dB 的初筛要求。这里比较的是受限模型族的理想分数，不是新模型实测收益。

### 4.3 与现有误差的重合

“标签路损超过直达上界 1 dB”的像素约占有效像素的 8.43% / 8.39%。这些位置承载 C82 总平方误差的 44.86% / 44.38%。

但这不是“已解释 44% 的错误”。它只说明硬直达约束冲突与现有大误差有较大重合。原因可能包含候选几何、测量和发布过程的不一致；本轮没有把原因唯一定位。

同样，本轮的“全可见”由候选几何计算，不是官方真实传播状态。不能据此直接宣布原始标签错误。

### 4.4 计算检查与修复记录

- 平地解析直达解通过；最大相对误差低于 9×10⁻⁶。
- 人工山脊同时产生可见与遮挡区域；功率非负。
- 独立 CPU 脚本从保存数组和原标签重算下限，与原计分一致。
- 首次运行的严格非负断言发现插值权重有 −2.22×10⁻¹⁶ 的浮点舍入。只对该数值误差截零并重新归一化；原旧代码未修改。失败记录保留，全部结果重新计算。

证据：CC/src/c131_direct.py、CC/src/c131_direct.cu、CC/scripts/c131_verify_floor.py、CC/audit/c131_transport/direct_n*_monitor/、CC/audit/c131_transport/initial_roundoff_failure.json。

## 5. 独立求解器检查：下限不能外推成物理极限

先按地形抽取 8 张 monitor 图，再检查它们的 C131 结果。索引为 9292、7373、10906、6047、2922、24259、17664、20332。抽样不是按本轮误差排名挑选。

### 5.1 地形可见性基本一致

在同一批候选接收积分点上，比较自建三角网格查询和 Mitsuba 原生射线查询；查询中只有地形，不含接收测量网格。

8 张图中，7 张的三角面平均可见性完全一致。另 1 张只有 4 / 130,050 个三角面的可见比例不同。像素直达功率的零／非零集合在 8 张图上全部一致。

这排除了这些样本上明显的基础地形遮挡查询错误。它没有验证候选网格等于原始网格，也没有验证最终 Radio Map 测量过程。

证据：CC/audit/c131_transport/visibility_crosscheck.json。

### 5.2 官方 Radio Map 计算的直达功率不同

保持候选地形、TX、RX 网格和发布映射一致，用官方 1.1.0 RadioMapSolver 只计算直达，关闭反射、漫散射和折射。以下仍是固定该 D 后、允许任意非负补功率的理想下限：

| 8 图直达计算方式 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| 自建 256 点／三角面面积求积 | 2.000610 | 2.348877 |
| 官方求解器，每 TX 800 万射线 | 1.495930 | 1.692789 |
| 官方求解器，每 TX 3200 万射线 | 1.384490 | 1.635568 |
| 官方求解器，每 TX 1.28 亿射线 | 1.426863 | 1.726736 |

这些数字不是完整传播模型的 RMSE。有限射线结果还未充分收敛，也不是原始生成时的 40 亿射线和多种子流程。不能挑最小值作为新成绩，不能把它们当作原始数据的误差下限。

只改变“射线穿过接收网格后的数值延续方式”、不改变任何 H/TX/接收网格坐标时，3200 万射线的下限会变为 1.666302 / 1.942793 dB。这说明接收测量的数值过程能影响细尺度结果；不说明这个变体更正确或更接近标签。

## 6. 这些功率差是否直接解释 C82 残差

使用同一批 8 图做一个固定探针。只在 H/TX 计算为全可见、两种直达功率都非零的位置，令：

delta = clip(−10 log10(Dofficial / Dnative), −20, 20)，
yprobe = yC82 + delta。

其他位置保持 C82。截断和单位系数在检查分数前固定。没有拟合系数，没有用标签筛选待修正位置，也没有在 monitor 上训练。

| 方法 | 415 MHz RMSE | 5.775 GHz RMSE |
|---|---:|---:|
| 原 C82，8 图 | **2.249131** | **2.538968** |
| 加 800 万射线测量差 | 3.138138 | 3.487783 |
| 加 3200 万射线测量差 | 2.846595 | 3.176958 |
| 加 1.28 亿射线测量差 | **2.712394** | **3.035701** |
| 用官方／改动接收延续方式的差异修正 | 2.621880 | 2.935641 |

1.28 亿射线的测量差与真实 C82 残差，在探针覆盖像素上的向量余弦只有 0.0461 / 0.0402。虽然其中部分大误差点的修正符号准确率为 65.0% / 62.6%，但它只覆盖原大误差点的 27.1% / 26.4%，并且全体像素 RMSE 变差。

**因此，不把“发现数值差异”写成“找到主误差来源”。这个固定修正没有提分价值；本轮不继续增加射线或调整融合系数。** 这一负结果只否定被测的直接修正，不排除未来模型以不同方式利用传播信息。

证据：CC/scripts/c131_measurement_alignment.py、CC/audit/c131_transport/measurement_alignment.json。

## 7. 对主方案的具体修订：尚待实现和验证

### 7.1 保留共享算子，解除未经验证的硬直达下界

原式可以保留其计算分工，但 D 不能直接等于当前候选直达数组并永久固定。建议把候选传播状态与发布观测过程分开：

P = Pno_diffuse(H,t,f) + Aθ(H,f) Σ Kθ(H,f)^k Qθ(H,t,f)，
Ghat = Mθ(H,t,f; P)，
yhat = −10 log10(Ghat)。

这里 P 表示进入候选接收单元的线性功率；Mθ 表示从候选单元到发布像素的有效测量关系。有效覆盖若需校准，应作用于每条路径或每个接收积分位置，再汇总到像素。不能在最终 dB 输出端加一个任意残差，就把它命名为物理测量模型。

这只是接口设计。Mθ 的具体参数化还没有经过证据筛选。它不应使用地形 ID、每图自由参数或留出标签。跨地形共享的有界覆盖因子可以作为候选，但若它不能从 H/TX 预测正确位置和幅度，就应停止，而不是放宽成无约束修正器。

Mθ 也不能自动被解释为真实物理衰减。它可能只是在拟合候选几何与发布流程的有效差异。必须以“固定测量／可校准测量”的独立对照报告增量。

### 7.2 状态与单位

地表节点状态应有明确单位与面积归一化。可以采用分面侧的出射功率／辐射强度，再由角分布产生连续射线。若使用极化协方差，应保持半正定；不同路径按功率相加，单条镜面／折射路径仍保留必要的偏振变换。

K 不接受当前 TX 编码。几何边、距离、法向、可见性与频率响应决定传播。TX 只通过 Q 改变照射状态。参数在不同地形之间共享，不能给每个地形学习一张自由矩阵。

功率守恒约束需带上节点面积和角域权重，不能只要求一个未经单位定义的矩阵行和小于 1。远处连接可以稀疏；首段、末段及镜面覆盖保留细几何。

### 7.3 保留多 TX 差分监督，但单独测增量

全图 dB 平方误差为主项。近邻差值与跨 TX 的近邻差分可以作为辅助项。所有点对都必须标签有效；标签不能进入 Q、K、A 或 M 的前向。

同一地形每批 2—4 个 TX，共用 K，并轮换覆盖多 TX 数据。普通像素仍按原计分分母参与主损失。不要让辅助采样再次改变地形和频段权重。

多 TX 差分本身不增加可观测信息。它改变监督方式，只有在新状态能够表达相关关系时才可能有效。本轮没有运行该损失对照。

### 7.4 首轮对照和停止条件

完整网络初筛应至少包含：

1. 同一 monitor 上的 C82。
2. 有效测量可校准、保留连续路径方向的共享传播模型。
3. 与 2 使用相同测量模块、节点、连接、数据与训练预算，但合并方向的模型。
4. 与 2 使用相同传播结构，但固定候选直达／测量关系的控制。

随后只在冻结的模型上单独打开跨 TX 差分监督。比较方向时，不能同时改变校准能力，否则无法判断收益来自哪里。

原 128 地形全图初筛要求双频分别降低至少 0.20 dB。通过后冻结方法，在 484 地形确认集上要求双频分别降低至少 0.30 dB。各区域都按原像素分母报告 SSE、RMSE 和覆盖比例；同时看普通区域是否被损害。真值辅助的下限、尾部筛选分数和 8 图结果都不能替代晋级分数。

1,024—4,096 个节点、16—32 条连接、3—6 轮传输仍只是预算候选。连续镜面路径和混合路径的检索成本尚未测量。完整推理时间必须包括构图、候选搜索、可见性、接收求积和发布映射，不能用单个直达内核的耗时代替 500 ms 预算。
