# C123–C124 提分对照结果（2026-11-08）

结论：本轮没有做出大幅提分版本。C123 大网络和 C124 候选路径分布均未达到双频扩训门槛。正式版本仍为 C82，官方固定 VAL RMSE 仍为 2.246377 / 2.579150 dB，均值 2.412764 dB。本轮未使用官方 VAL 选择或评价新模型，也未提交网站。

## C123：扩大网络并保留原始地形细节

15,214,786 参数，8 层全局轴向注意力与局部卷积分支。实验组的全局分支通过 4×4 像素重排保留 1 m 原始地形，对照组的全局分支先平均。两组局部分支均保留原始分辨率。相同初始化、训练数据、优化器、8 epoch 与选择规则。

| 128 个 TRAIN 留出地形，完整有效像素 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| C82 | 2.146391 | 2.418014 |
| 先平均地形 | 2.145572 | 2.417161 |
| 保留原始细节 | 2.145354 | 2.417014 |

原始细节版相对 C82 仅改善 0.001036 / 0.001001 dB。同一网络在固定 16 图上 600 步拟合到 0.838238 / 0.739289 dB，梯度正常。因此，单纯扩大容量、避免地形平均，没有解决跨地形预测。小集拟合不证明可泛化到 1 dB。

## C124：保留候选路径的延迟—到达角功率分布

输入仅来自已发布的地形和 TX。对同一候选地形，用 8192 个接收方向追踪散射贡献，按额外路程和相对到达方位分为 8×16 个功率箱。两个频段共 256 个通道。仍沿用 C69 的 TX 约定和 C70 的三个接收单元插值，不重启 C95 数值映射路线。它是候选传播计算，不是真实 CSI、PDP 或 PAS。

两组均使用旧 169 个特征、2 个精确总功率和 256 个谱通道。对照组将同样的总功率均分到各箱，实验组保留计算得到的候选分布。两组均为相同参数的 CatBoost 连续路径损耗残差回归：深度 10、最多 3000 棵树、相同学习率与种子、提前停止规则。目标是 Y−C82；掩码仅用于损失与计分。

固定 FIT 为 2815 图、1984 地形、每图 1536 点。monitor 为 628 图、128 地形、每图 2048 点。有效点数分别为 1,276,943 / 1,182,747。以下是采样有效像素 RMSE，与 C123 完整像素口径不能直接混比。

| 同一 TRAIN monitor | 415 MHz | 5.775 GHz |
|---|---:|---:|
| C82 | 2.140018 | 2.411312 |
| 只保留总功率 | 2.131563 | 2.394950 |
| 保留候选路径分布 | 2.131481 | 2.395681 |

路径分布版相对 C82 改善 0.008537 / 0.015631 dB；相对总功率对照，低频仅改善 0.000081 dB，高频变差 0.000731 dB。

- 415 MHz：路径分布额外收益的地形配对 bootstrap 95% 区间为 [-0.001035, 0.001233] dB，跨越零。
- 5.775 GHz：路径分布额外收益的地形配对 bootstrap 95% 区间为 [-0.002052, 0.000611] dB，跨越零。

这说明本次保留的候选路径分布没有带来可确认的额外收益。总功率对照的微小改善不能归功于路径谱。独立 NumPy float64 计分与训练输出一致；8192 方向分箱前后总功率的最大相对差为 0.005702%。

## 剩余误差集中在哪里

按 C82 原误差绝对值至少 5 dB 固定选取困难点，只用于评价，不作为输入或部署时的选择条件。

| 路径分布版在困难点的表现 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| 困难点比例 | 3.76% | 4.54% |
| 占新模型平方误差的比例 | 74.94% | 76.59% |
| 修正方向准确率 | 54.66% | 55.74% |
| 困难点 RMSE | 9.5208 dB | 9.8411 dB |

决定分数的少数严重错误仍未解决。这里没有证据支持继续扩大这两条训练路线。

## 原有相近条件、反向误差点对的复核

使用 C122 之前就固定的 24 张图与原有 645 个点对，仅推理，未拟合。这是选定失败案例的诊断，不能当作总体性能估计。低频 357 对，高频 288 对。每对两个端点分别需要增加和减少预测路径损耗。

| 路径分布版点对结果 | 415 MHz | 5.775 GHz |
|---|---:|---:|
| 两个端点修正方向同时正确 | 15.41% | 23.26% |
| 端点 RMSE | 9.4769 dB | 9.6932 dB |
| 真实路径损耗差中位数 | 15.3750 dB | 15.6562 dB |
| 预测路径损耗差中位数 | -0.4190 dB | -0.1091 dB |

这些点对中的高损耗位置和幅度仍没预测准。不能用小集能拟合来替代跨地形证据，也不能把这两条路线失败解释成“现有地形必然不含信息”或“1 dB 不可能”。本轮仅表明这些具体配置未达到提分门槛。
