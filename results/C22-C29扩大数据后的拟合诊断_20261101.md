# C22–C29：扩大数据后学不好的原因与改进对照

本阶段没有得到接近1 dB的新参赛版本。官方固定验证仍是C10：综合 **3.1775908266 dB**；415 MHz **2.9672021445 dB**，5.775 GHz **3.3879795087 dB**。没有新增官方VAL候选或网站提交。

所有实现、训练、评价和分析均在本CC目录独立完成。没有读取或复用其他AI在CC外的代码、模型或特征。实体1、3、4按完整UUID运行；过程保留每个作业实际GPU、代码快照、协议、初始模型、地图顺序和查询顺序的记录。原始数据只读，C10权重哈希未变。

## 核心判断

1. **原小集与全量试验的重复次数严重不等。** 原四图每图4500次；原23158图FIT每图6或7次，均值6.218，相差723.7倍。小集成功不能证明原全量预算足以拟合全部地图。

2. **同一批困难地图，联合优化确实增加了拟合误差。** C28在相同四张难图、相同4500次访问、相同初始模型和像素序列下，只加入其他地图梯度就使双频误差增加0.231170 / 0.262178 dB。这是所选四图和该训练流程的直接控制结果，不代表全数据总体分解。

3. **不能把难图续训的剩余误差当作网络容量下限。** C28使用已有模型、2e-4学习率、4500步余弦周期。原小集使用随机初始化、1e-3学习率、6500步周期。C29按原小集完整配置，仅换成四张难图，在5500步达到0.490 / 0.379 dB。架构没有变化，初始模型哈希与原四图参考一致。这个结果证明该架构能够记住这些难图；不证明公开输入已经包含全部物理变量，也不保证未见地形可以达到相同误差。

4. **把学习率提高到小集水平，不能直接解决128图拟合。** 同父模型、同3000步、同地图和像素序列下，5e-4相对2e-4只改善0.023062 / 0.022064 dB；1e-3只改善0.012167 / 0.008097 dB。未通过双频各0.10 dB的预设扩大门槛。

因此，目前有证据支持“训练曝光不足和跨地图联合优化共同造成问题”。尚不能给二者分配可相加的百分比，也不能据此确定剩余误差主要来自网络表征不足还是未记录的仿真细节。没有证据支持只靠换学习率、扩宽最后几层或继续原配置就能达到官方双频1 dB。

- 四难图5500步达到0.489853 / 0.379305 dB。

## 本阶段结论与限制

已经完成这轮诊断和针对性改进，没有得到经过验证的大幅提分方案。未通过预设门槛的分支不继续占用GPU。没有后台训练或自动后续队列。

当前最明确的缺口，是在大量地形间学习可复用的细尺度传播表征。四图拟合成功可能包含记忆地图，不能证明物理信息完整。已有地形—标签对应检查未见整图粗错位；实际原始网格、连续TX坐标、插值前功率仍缺失。现有对照不能把“输入未记录”与“网络未提取”完全分开，更不能将目标1 dB视为已经可保证。

后续若继续改变共享表征，需要在同等数据访问预算下，同时改善完整FIT和地形隔离DEV；仅让四图误差更低或增加参数量，不能作为官方提分依据。
