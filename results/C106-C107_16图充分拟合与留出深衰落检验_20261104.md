# C106–C107：16图拟合达标，留出泛化未达标

完成了本轮小集拟合与原留出集检验。没有获得大幅提分版本，没有扩训。

## 固定16张图的结果

沿用 C105 的同16张FIT图，来自10块地形。低频/高频有效像素为1,043,016 / 973,096。原始标签与掩码来自发布TRAIN文件；标签、掩码和图ID不作为输入。全部候选使用同一套58通道H/TX派生输入与冻结C82功率图。

网络为原生1m卷积与128/64分辨率轴向注意力，1,215,234参数。C106从与C105small完全相同的初始状态出发。没有增加参数，没有加入每张图的可学习参数。骨干继承C99global第11轮，父模型此前在5508块FIT地形训练；本轮不是从零只训练10块地形。

验收比汇总RMSE更严格：所有16张图的两个频段分别<0.98dB，汇总双频<0.95dB。C107另外要求基线漏掉的深衰落子集双频功率RMSE<0.95dB。

C107两组从同一个C106原设置第4000步权重开始，均重置AdamW，lr=1e-4、wd=.01、batch8和抽样顺序一致。唯一差别为正残差至少5dB点的损失权重1或8。双方都运行到新增1100步时，普通损失的深衰落子集RMSE为 1.456705 / 1.362701；加权为 0.923535 / 0.837594。加权组按预设全部条件首次通过，普通组继续到3000步预算仍未通过尾部功率门槛，但总体及每图已低于1dB。

加权组训练定位精确率 90.105912 / 90.048822%，召回率 93.333865 / 93.704718%，AP 0.969803 / 0.972772。这些是训练结果，不能用作未见地形的成绩。

## 同一留出集的定位与功率

深衰落子集定义为有效标签满足真实路损−C82预测≥5dB，即相对C82漏掉的弱点。定位分数为新预测−C82，固定阈值5dB。该定义不是所有物理深衰落的全集。功率dB误差与对应路损dB误差绝对值相同；此处按路损标签计分。

权重、步骤和候选选择先按FIT冻结，再查看原128地形监测和484地形确认。确认使用同1934张图、每图相同2048预抽样位置；有效像素3,930,241 / 3,587,418。此留出集曾用于历史研究，不称全新盲测；不是官方VAL，也不是全像素评分。

## 能确定什么

1. 原来200步的小集拟合检查不充分。相同网络和输入只增加训练步数就通过32项1dB验收。
2. 在固定16张图上，原网络的表示能力不是达到本次1dB目标的硬阻塞。稀有弱点功率也可在不增加容量时拟合到1dB以下。
3. 训练分配会影响稀有点收敛。相同新增1100步，加权组的弱点功率明显优于普通损失；整体RMSE存在取舍。
4. 本次去掉权重衰减略早达标，所试学习率下降安排更慢。单次固定种子不足以给出普遍最优优化器结论。
5. 跨地形泛化没有解决。训练图定位/功率好，留出定位与功率差；不符合扩训门槛。

## 仍不能确定什么

16张图只有10块地形。拟合成功只检验有限小集的表示与优化能力，不能证明相同网络足以拟合完整FIT，也不能证明架构对未见地形合适。有限独特输入的记忆不能区分缺少传播信息与缺少正确的归纳偏置。不能由这些结果宣称输入存在大于1dB的不可约误差。

## 核验与计算

全部训练/推理通过run_gpu.sh按完整UUID限定1、3、4号卡，GPU身份写入每组config。H100 batch8实测约0.079秒/更新。C106原设置约316秒、去掉wd约293秒、A800学习率组约456秒；C107加权约87秒，普通损失约238秒。主比较按更新步数和同初始化，硬件耗时分开记录。

保存的float32预测均用NumPy float64独立复算；逐图、逐频段与CUDA训练统计一致。确认分数另行逐块累计核对。每批确认还逐值核验原始标签、掩码和C82基线与已有面板完全对应。AP用手算排序和并列分数用例核验。16图未发现完全相同H/TX输入的标签冲突；这不代替完整数据审计。

C107首次启动在保存配置时发生GPU字段重复，尚无训练更新；修复后从同一父权重重启。失败日志与空结果目录保留，未覆盖有效成果。没有系统修改、GPU重置或停止无关任务。
