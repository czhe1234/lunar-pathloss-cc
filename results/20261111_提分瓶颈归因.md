# C82 提分瓶颈归因

2026-11-11。频段顺序始终为 415 MHz、5.775 GHz。

## 卡在哪一步

已测试的残差模型在未参与该模型训练的地形上，无法稳定分配大修正。位置、方向和幅度的误差会抵消修正收益。候选物理计算也无法提供一致的修正信号。它在大量高损耗点上给出的直达功率，已经超过发布标签允许的总功率。

本次用冻结预测和缓存复算。四组结果来自不同面板，分别注明范围。真值只用于事后计分和反事实诊断。未训练、未重算模型推理、未使用 GPU。

## 1. 完整官方验证集的误差集中在少量像素

完整官方固定 VAL 共 680 块地形、每频段 2,330 张图。按官方掩码累计有效像素的平方误差总和（SSE）。

| 指标 | 415 MHz | 5.775 GHz |
| --- | ---: | ---: |
| 有效像素 | 151,537,682 | 135,926,253 |
| C82 RMSE，dB | 2.246377 | 2.579150 |
| 绝对误差 ≥5 dB 的像素数 | 6,361,445 | 7,153,832 |
| 上述像素占有效像素比例 | 4.20% | 5.26% |
| 上述像素贡献的 C82 SSE | 76.30% | 78.27% |
| 只把上述像素按真值改准后的 RMSE，dB | 1.094 | 1.202 |

680 块地形中，每块都出现过绝对误差 ≥5 dB 的像素。双频共同有效的像素中，有 3,222,864 个在双频均达到该阈值。其中 96.26% 的修正方向相同。这个统计说明存在双频共同误差，无法单独识别其物理来源。 [完整结果](../audit/plateau_diagnosis_20261111/official_error_budget.json) · [复算脚本](../audit/plateau_diagnosis_20261111/official_error_budget.py)

## 2. 已测的修正分配怎样抵消收益

C125 固定同一个残差预测器，只替换修正权重。范围是原 128 块 TRAIN 开发地形、628 张图，每图 2,048 个固定抽样点。按频段掩码计分，双频有效点为 1,276,943 / 1,182,747。该面板已多次用于开发。

| 条件 | 415 MHz RMSE，dB | 5.775 GHz RMSE，dB |
| --- | ---: | ---: |
| C82 开发参照 | 2.1400 | 2.4113 |
| C125 用模型预测的软权重分配修正 | 2.1564 | 2.4288 |
| C125 用真实大误差成员分配修正，仅诊断 | 1.9445 | 2.2369 |

模型预测的软权重在 ≥5 dB 的大误差点减少了 16.75 万 / 15.06 万 dB² 的 SSE，却在其余点增加了 25.71 万 / 25.09 万 dB²。约 95% / 89% 的其余点损失来自修正概率低于 0.5 的点。大量小修正也会损伤全图分数。

同一面板上的 C124 出现第二种抵消。大误差点上，方向正确的修正降低的 SSE，被方向错误的修正抵消了约 80% / 79%。因此改善位置分配后，还需要改善方向与幅度。C125 的真值对照同时改变修正位置和强度，不能把两者贡献独立分开。 [复算结果](../audit/plateau_diagnosis_20261111/saved_residual_sse_decomposition.json) · [原始对照](C125-C126_大误差方向与状态判别对照_20261108.md)

## 3. 当前物理计算怎样把修正推向错误方向

仍使用同一开发面板。若直达功率正确，总功率至少等于直达功率。因此标签路损不能高于直达路损。在 C140 候选计算下，下界冲突定义为候选直达功率比标签允许的总功率高出超过 1 dB。

| 指标 | 415 MHz | 5.775 GHz |
| --- | ---: | ---: |
| 下界冲突点 | 155,529 | 97,699 |
| 占有效点比例 | 12.18% | 8.26% |
| 冲突点包含的 C82 SSE | 66.88% | 42.70% |
| 只用真值改准冲突点后的整体 RMSE，dB | 1.232 | 1.825 |
| C82 强制满足当前直达下界后的 RMSE，dB | 2.708 | 2.829 |

硬约束降低预测路损。在大量 C82 已低估路损的像素上，这会把预测推得更远。C140 交叠比例描述现象，不能当作修好直达计算后可消除的误差。反事实结果给出另一条限制，即使冲突点全部被改准，仍有明显的残余误差，尤其在高频。 [复算结果](../audit/plateau_diagnosis_20261111/direct_conflict_overlap.json) · [复算脚本](../audit/plateau_diagnosis_20261111/direct_conflict_overlap.py)

## 4. 重复发布记录能排除什么

8 对 TRAIN 记录具有相同的发布高程和 TX 像素坐标。比较双频各自共同有效且离 TX 至少 10 m 的像素。只要任一记录的 C82 误差 ≥5 dB，就计入该频段的并集。

| 指标 | 415 MHz | 5.775 GHz |
| --- | ---: | ---: |
| 并集中的像素对 | 25,185 | 32,255 |
| 两份记录都属于大误差的比例 | 99.90% | 99.06% |
| 双方都为大误差时的修正方向一致率 | 100% | 100% |
| 并集上标签间差异的 RMS，dB | 0.074 | 0.221 |
| 并集上两份记录的合并 C82 RMSE，dB | 9.487 | 9.700 |

这些重复记录的标签差异无法解释其大误差。两次记录是否共享原始场景或随机种子仍未核实。这组结果不能用于估计整个数据集的随机噪声或输入信息上限。 [结果](../audit/plateau_diagnosis_20261111/duplicate_tail_check.json) · [复算脚本](../audit/plateau_diagnosis_20261111/check_duplicate_tail.py)

## 还未定位的源头

当前已定位两处提分失败。学习模型没有稳定读出新地形的局部强弱状态。当前物理计算与发布标签又不相容，不能用来稳定监督该状态。现有证据不足以区分原始网格、实际连续 TX、接收面交点或发布插值各自的影响，也不足以判断只用发布 H/TX 的误差下限。

C142 用固定几何和方向隔离后端，已完成 LLVM 核验。CUDA 待空闲许可卡。若后端差异不足以解释反例，优先用一个内部反例的原始网格、实际连续 TX、插值前接收单元功率及导出设置逐阶段核对。例如 TRAIN 00414_00 的像素 (23,38)。当前固定网格对这个像素的直达功率超过标签允许功率 17.53 / 17.23 dB。 [C141 反例记录](../audit/c141_direct_receiver/remaining_finite_counterexamples.csv) · [C142 当前接续点](../audit/c142_backend/README.md)
