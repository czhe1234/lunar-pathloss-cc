# C38 月面路径损耗模型

输入：单张256×256地形高度图（米），整数TX行列坐标。
输出：float32数组[2,256,256]，依次为415MHz与5.775GHz路径损耗，单位dB。
Predictor只从输入地形与TX计算294项描述量，然后通过周期数值嵌入与8成员共享参数网络预测。

官方原版计分结果（完整固定VAL，2330图/频段，680地形）：
415MHz：2.6727180785dB。
5.775GHz：3.0805375616dB。
combined_rmse_db_masked：2.8766278200dB。
相对C10两个频段下降9.92%与9.07%。双频各≤1dB目标尚未达到。
未进行网站提交。运行时限仍需按比赛指定硬件核验。

训练包含两个阶段，均只使用官方TRAIN：
1. C37全量再拟合：每图256点，22213步。
2. 从上述权重继续C38：每图1024点，35540步。
第二阶段步数由内部DEV选定的32000步按全TRAIN/内部FIT样本量比例换算。
官方VAL未用于梯度、早停或步数选择。原始294项归一化统计保持冻结。

在transformer的CC目录调用：

    ./run_gpu.sh 3 releases/C38_20261102/predict.py --heightmap /ABS/height.npy --tx-row 128 --tx-col 128 --output /ABS/prediction.npy

仅允许实体1、3、4号卡，启动器按完整UUID限制并核验。
本项目的实际输入输出文件及所有新增工作继续位于CC。
也可导入src/c34_inference.py中的Predictor，将本包model作为模型目录。

实际发布目录已在同一H100上验证4张图，与批量导出逐像素一致。
推理接口不读取样本索引、标签、有效性掩码或特征缓存。
依赖：PyTorch2.6.0+CUDA12.4、NumPy、SciPy；无需射线追踪包或LightGBM。
