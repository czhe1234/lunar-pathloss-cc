# C37 月面路径损耗模型

输入：单张256×256地形高度图（米）与整数TX行列坐标。
输出：float32数组，形状[2,256,256]。频段顺序为415MHz、5.775GHz，单位dB。
推理不读取样本编号、标签、有效性掩码或预计算特征缓存。

本版本使用294项独立地形/TX表征、周期数值嵌入、8成员共享参数集成、3层宽度1024的网络。
全量TRAIN再拟合使用25720图，每图256点；22213步。官方VAL未用于梯度或早停。
官方原版计分脚本：415MHz 2.7165042517 dB；5.775GHz 3.1194313666 dB；
combined_rmse_db_masked=2.9179678091 dB。
完整固定验证2330图/频段、680地形。双频各≤1dB目标尚未达到。未进行网站提交。

在transformer的CC目录调用（只允许实体1、3、4，启动器按完整UUID核验）：

    ./run_gpu.sh 3 releases/C37_20261101/predict.py --heightmap /ABS/height.npy --tx-row 128 --tx-col 128 --output /ABS/prediction.npy

调用方保证输入输出路径在用户授权范围内。本项目所有新增工作仍在CC。
也可导入src/c34_inference.py中的Predictor，模型目录为本包model。
接口在与参考批量导出相同的A800上对4张图逐像素一致。
H100与A800的BF16实现会有小数值差；首图观察到最大0.006859dB、RMS小于0.0002dB。
该跨卡差异不表示接口公式不一致。推理时延需按比赛指定硬件另测；官方评分器提示runtime未核验。

依赖：PyTorch2.6.0+CUDA12.4、NumPy、SciPy。无需射线追踪包或LightGBM。
源码、权重、配置、官方验证摘要、接口核验一起保存。
