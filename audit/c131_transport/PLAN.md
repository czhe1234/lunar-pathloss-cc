# C131 地表方向功率传输：实施前置检验
日期：2026-11-09。全部新增工作在 CC。授权设备为当时空闲的实体 1、3、4，使用 run_gpu.sh 的完整 UUID 限制。

## 主假设
按用户方案建立 H/TX → 地表受照功率 → 方向传播 → 接收面积测量的统一计算。地形传输规则跨 TX、跨地形共享。不能将物理量压成向量后用 MLP 猜残差，声称已经实现传播算子。

## 先查必须满足的条件
1. 发布 metadata 明确采用 Lambertian 散射。Sionna RT 1.1.0 的 LambertianPattern = abs(ko_local.z)/pi，角分布不依赖 ki_local。入射方向仍影响 Fresnel 能量、极化、受照位置与面侧。自由学习漫散射的方向记忆不是必需物理量；连续方向优先用于镜面、透射及含它们的混合路径。
2. 当前 CC 的 C92 已经计算原生三角面上的多次双侧漫散射，C79 已跑过低射线数的官方完整机制模拟。这些不等同于新可训练共享算子，但也不能把“加入多跳”当作尚未尝试的新信息。
3. 任意非负分量之和满足 G>=D，故 yhat<=-10log10(D)。若固定候选几何给出的 D 已超过标签功率，后续 K/A 无论多强均不能降低该点功率。先量出这个模型族的误差下限，不能在此条件未知时扩训。

## 本轮检验
沿用 C127 的原 128 地形、628 图 monitor，完整 256x256 有效像素；不接触官方 VAL。冻结既有候选网格、TX 高度和映射，不搜坐标偏移或新拓扑，不重启 C95。三角单元分别使用 1/4/16 点面积求积，检验积分收敛。
输出两种下限：
- D 仅包含无遮挡直达；
- D 包含既有材料模型的直穿透射。
其它功率允许逐像素借助真值任意非负补足。因此得到的是限定模型族的有利诊断，不是可提交预测，也不是原始 H/TX 的信息下限。
公式：e_floor=max(y + 10log10(D), 0)。D=0 时不施加有限路损上界。按所有有效像素累计 SSE/count 后开方。
对照 C82 同点分数、违反直达上界超过 1 dB 的点数、这些点占 C82 SSE 的比例。掩码、标签在物理前向结束后才用于计分。
先通过平地解析解、山脊遮挡和非负性检查，再完成三组积分精度。全部原始数组和逐图 SSE 留存。

## 后续晋级
若固定直达项已经阻止双频 1 dB，则先修改模型接口，使有效受照覆盖/测量关系可以被 H/TX 条件化校准；不能仅在其后添加正功率，也不能宣称原始输入必然不足。
新算子的完整原生全图对照仍为 C82、方向保留模型、合并方向模型；同数据、初值、预算，随后单独对照跨 TX 差分监督。
128 地形双频各降 >=0.20 dB 才做冻结后的 484 地形确认；确认各降 >=0.30 dB 且地形配对区间为正才扩训。真值辅助结果不晋级。
