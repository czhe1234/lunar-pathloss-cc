# 冻结 C4 剩余误差归因

用户要求：不再训练，独立区分地形与标签对应、输入缺失、模型未学会。所有新增文件在 CC，只读原始发布数据和 CC 自己的源文件/检查点。仅 GPU3 完整 UUID。没有优化器、反向传播、权重更新或传播仿真。

1. 复核相同输入重复样本的标签一致性。重复记录不等于独立随机种子重复，不能据此估计全体数据的噪声下限。
2. 在同一冻结 C4 全量模型上比较按单/多 TX 与地形起伏分箱匹配的训练集样本和全部官方验证。输入只用地形和 TX；掩码只用于统计。
3. 用临界 TX 高度表征检查几何/标签边界对应。固定高度、每地形常数、整数高度取整相位是事前列明的诊断假设。参数枚举只作标签知情诊断，不用于部署或生成新版本；用分开的接收位置/TX 检验迁移。开发多 TX 地形作发现，另选训练地形和官方多 TX 地形作确认。
4. 检查最终模型的分区误差、双频共同误差、同地形 TX 响应、粗空间残差和 FP32/BF16 前向差异。
5. 不把标签知情上限当可用模型。不把未解释误差直接叫缺失信息或不可约噪声。结论分别列出支持、反证、仍不可识别的部分。

官方验证已用于本轮冻结模型的事后诊断。本轮不依据诊断重新训练或修改官方预测。将来若据这些诊断设计模型，应保留该使用记录。
