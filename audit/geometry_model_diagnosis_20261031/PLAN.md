# 地形—标签对应及模型误差诊断

用户要求：先核对地形与标签，再判断模型哪里没学对，提出有证据的办法。禁止训练。所有新增工作在 CC；只读原始 data 顶层发布文件及 CC 自有结果。不得读取其他 AI 的代码、特征或结果。

顺序：
1. CPU 检查全部 train 标签最低路损点与 TX 索引；核对行号、hm_row、双频及掩码。
2. 在预先选择的 128 个不同开发地形上，比较原地形、旋转/翻转、半像素/一像素偏移、三角面插值及接收高度假设。以标签自身的归一化功率结构检验几何对应；这些只是诊断，不修改数据。按地形划分发现/确认两半。
3. 对已保存的全部开发预测，检查几何明确可见区中标签的基础衰减归一化值、接收面掠射角及模型误差。有限面积接收、插值、Monte Carlo 与点接收假设分开，不能将近似矛盾直接称作错误标签或不可约噪声。
4. 在对应关系检查后，用冻结检查点评估预先抽取的 fit/dev 样本。必要的前向计算仅使用实体 3 的完整 UUID；不创建优化器、不反向传播、不更新权重。区分拟合不足和泛化差距，检查误差空间尺度及输出敏感性。
5. 只有输入可计算、不使用真实标签作门控的固定修正可作为可部署候选；其余用真值的变换只用于定位问题。保留失败方案，不把诊断收益冒充正式验证成绩。

不开启官方 val 调参、训练、传播仿真或新的自动训练队列。若检查仍不足以确定原因，明确未辨明的环节，不声称已找到能达到 1 dB 的方法。
