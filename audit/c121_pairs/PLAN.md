# C121 同地形同 TX 的反向误差对照

问题：当前 H/TX 表征中哪些差异能区分 C82 的正负修正方向？

先固定场景、TX 和接收点邻域，只在 TRAIN 的既有 FIT/128 地形 monitor 中分析。正式 VAL 与 484 地形 confirmation 此阶段不读。残差定义 Y-C82：正值要求增加路径损耗（减弱功率），负值要求减少路径损耗。

每频段从现有预抽样点中取 |残差|>=5 dB 的锚点；先以正锚点研究遗漏弱点。邻点在 ±4 像素方框中，边缘不复制，自身排除。对方必须同频段有效。反向为残差<=-5，同向为>=5。按输入几何差异匹配，标签仅决定诊断分组，不进入距离或预测输入。

固定紧匹配条件：接收高度差<=0.25m、中心化7x7 H差RMS<=0.10m、射线方向角<=0.025rad、相对三维距离差<=0.03、四面余弦差RMS<=0.01。同一地图固定整个发布H和TX。记录更紧一半阈值以及不加阈值的分母，不因结果调整阈值。先在候选中按五个归一化差异平方和最小选择反向点。同向控制尽量匹配反向点的几何距离（0.8~1.25倍）及像素半径（差<=1像素）；没有控制保留缺失，不伪造匹配。

对照原始局部H、当前169维、C118原生场表示（已有时），以及现有 C72 未平均供体特征。后者只读取已经计算的固定映射；不更换网格/接收面、不重启 C95。必须检查 C82 本身曾经获得哪些信息，区分“修正器压缩了信息”和“全系统根本没有信息”。

先验证任意点特征与 C101 缓存重建一致。保存实际地图ID、地形ID、TX、两个接收位置、两点标签/预测/残差和匹配距离。对标签选择产生的诊断优势，只称条件诊断，不当作可提交分数。

若发现遗漏特征：固定新增表征，在相同 FIT/monitor 训练一个受限读出对照（原特征 vs 增加表征）；正负尾部判断只用于筛选。连续功率修正必须在全部有效抽样点上评分，计算误改正常点的代价。只有同一484地形双频各改善>=0.30dB、地形配对95%区间均为正，才全像素核验并决定扩训。不得以微小改善扩大训练。

资源：CPU诊断先行。GPU若需要，只在实时确认空闲后，经 run_gpu.sh 启动允许 UUID；不排队抢占忙碌的1/3号卡，不干预任何其他任务。
