# 闭合地形与标签细尺度对应所需的最小原始记录

仅是本地核对清单，未向组织者发送。优先两个已有公开数值对应的样本：

- `02136_00`，官方 val index 行 807，HM 行 207，TX (row=194,col=160)，对应公开 sample 650。
- `02736_00`，官方 train index 行 10166，HM 行 2466，TX (row=199,col=46)，对应公开 sample 680。

索引从 0 开始。需要这些样本与旧仿真文件/随机种子的对应记录。

| 原始记录 | 最少字段 | 能决定的问题 |
|---|---|---|
| 物理地形网格和 RX 测量网格 | 原始 vertices、triangular faces、世界变换矩阵、坐标单位、tile 原点/裁切位置 | 真实三角形划分、地表高度与法向、RX 是否精确 z+1 m、像素原点或半像素差 |
| 实际 TX 对象 | 仿真时 `Transmitter.position` 三维数值；height lookup、平面坐标采样与取整方式 | 实际 AGL、连续 XY 与 one-hot 像素的对应；不使用显示锥体反推 |
| 插值前接收数据 | 各频段每种子的 `cell_centers`、`path_gain`、有效/未命中标记、triangle ID | 单元平均与点可见性的差异；随机种子方差；双频是否同一接收网格 |
| 精确导出步骤 | `griddata` 输入/输出坐标、method、NaN/0 处理、watt_to_dbm 位置、nanmean 所在数值域、flip/crop/transpose、最终 fill、mask 生成、float16 转换 | 中心网格到规则网格的具体插值权重和定位；功率域/dB 域操作差异 |
| 来源固定信息 | Sionna/Mitsuba/DrJit 版本或 commit、场景文件、seed 列表、合并计数、导出代码版本 | 同一数据版本的可复现核对 |

有了这些记录，先重放已有数组的导出，不重新射线追踪、不训练。逐步比较：接收面高度 → 单元中心 → 插值后的未补洞图 → 最终标签/掩码。每步对两例统计坐标偏移、数值差和遮挡边界差，再决定是否需要更广的样本。

如果只能提供当前规则网格的 pre-fill 数组，它仍可核对最终补洞和掩码，但不能代替插值前的三角单元数据。
