# C140：功率传输相容性与传播一致性公平对照
日期：2026-11-10。仅在 CC 执行。官方 VAL 不参与开发。

## 本轮问题
现有 H/TX 功率传输算子是否足够相容且数值稳定，可以作为学习约束？
若可以，相同网络、初始化、训练数据、采样顺序和优化预算下，加入传播一致性是否改善跨地形预测？
物理方程成立不等于当前候选网格、有限路径与求积实现准确。

## 固定数据
使用 C136 的 248 张 FIT 图（128 地形）和原始 monitor 的 628 张图（128 地形），沿用 C101 固定像素和权重。
FIT 与 monitor 按地形隔离。mask 只用于计分。原始 TRAIN 标签用于核验缓存，不读官方 VAL 标签。
C82 的同点 RMSE 为 2.140017876 / 2.411311753 dB（实际重算为准）。
sampled 初筛不能代替 128 地形全图验收，亦不是官方验证结果。

## 阶段 A：先检验，禁止跳过
1. 验证缓存像素、标签、mask、频段、索引一致。核对非负、有限性、单位与 dB 转换。
2. C135 全路径绝对功率直接形成 PL；在 FIT 上拟合每频段一个全局 dB 偏移，再冻结于 monitor。另报未校准结果，不能用偏移掩盖细尺度错位。
3. 检查必要条件 G_total >= G_direct，量化发布标签低于候选直达功率时的不可达误差。该结论只约束候选实现，不否定非相干功率物理。
4. 重算已保存加密求积版本之间的差异，包括总功率和直达分量。以同一交集有效点报告 RMSE、分位数、零功率与分区差异；精细版不是物理真值。
5. 在 C132 固定 H-only 稀疏 K 上，用 FP64 解 L = Q + K L 到相对 L1 残差 <=1e-8，检查非负性、列和 <1、迭代截断误差，并通过原 RX 算子生成绝对功率。与零跳、三轮和收敛解对照。该 K 只覆盖粗地表漫散射，不能宣称完整方向传输。
6. 对 C82 大误差点另报预测修正方向、幅度和 SSE；采用正负类实际比例作为方向基线。

## 阶段 A 的推进条件（分析前固定）
- 所用算子的两档加密计算在共同有效像素的 dB RMS 差各 <=0.10 dB；否则先修复数值问题，不把未收敛值当硬物理监督。
- 直接功率非负可达下界不能已经排除双频 1 dB；如排除，则修复直接/接收算子，不能只叠加散射。
- 通过数值条件还不等于标签相容。必须联合报告校准后误差、强弱顺序/修正方向和必要条件；不能仅凭低自洽残差判定相容。
- 若条件不通过，完成有证据的否定/局限报告和下一项可修复问题，不启动伪物理约束扩训。

## 阶段 B：通过后才启动匹配对照
主比较：lambda=0 与预定非零 lambda，两臂同结构、输入、初始化、种子、数据顺序、步数、batch、优化器及直接/RX 分支。
约束须真的联系 Q、K、L 与接收算子。禁止仅将物理量拼接后声称满足传输一致性。
残差使用收敛确定性算子；若使用随机射线，先处理平方残差的估计偏差。
未知的全局源/测量尺度只允许 FIT 校准。不能使用 label-assisted 自由隐状态作物理真值。
每频段原计分口径的 dB MSE 为主损失。传播约束不能改变主损失分母。
固定最后 checkpoint，不根据 monitor 挑训练轮次或反复调 lambda。
具体结构和预算在 A 通过后另写 preregistered_arms.json，开始训练前冻结。

## 验收与资源
sampled 筛查有明显收益后，128 地形全图要求两频段各下降 >=0.20 dB；
冻结后 484 地形确认要求两频段各下降 >=0.30 dB。通过才扩训。
包括普通点、大误差点、通视与遮挡区 SSE。计入构图/求积的整图端到端推理预算仍为 500 ms。
允许 GPU 1/3/4 的完整 UUID 见 GPU_POLICY.md；仅空闲卡，必须 run_gpu.sh 与 gpu_guard。
目前三卡都有他人任务；阶段 A 用 CPU，最多 2 线程。不得抢占/杀进程/重置设备。

## 阶段 A 补充：必要条件对照（运行前固定）
在相同 628 张 monitor 图上，对已保存 C82 预测使用 lambda=0、1、无穷的直达功率下界约束。此为零训练输出投影诊断，不冒充有无传播一致性网络训练对照。不依据标签形成约束或挑选 lambda。按地形 bootstrap 1000 次，并保存反例。
