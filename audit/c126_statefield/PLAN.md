# C126: full-terrain signed-state and conditional-amplitude learning
2026-11-08. Child implementation from C125 failure diagnosis.
Evidence: all-point regression sign ~55% is not an input-information ceiling; conditional sign reaches 64-70%. Conditional regression helps only with true membership; replacing membership with learned C118 probabilities loses the gain. Raw local/path views did not help. High-capacity old-input trees fit TRAIN direction >99% but transfer poorly. Therefore test targeted supervision on the full-terrain network, not further capacity or blend tuning.
Hold fixed: C123 native full-terrain axial backbone (15.2M), exact H/TX inputs58, C105 FIT2815 maps/1984 terrains and monitor628 maps/128 terrains, map inclusion weights, batch8, AdamW lr3e-4 wd.01, max8epochs and identical CPU-generated map order. Same initialized 12-channel head in both arms.
Outputs per band: logits for ordinary / positive residual>=5 / negative residual<=-5, plus conditional means. Ordinary mean=5*tanh(a0); positive=5+softplus(a1); negative=-5-softplus(a2). Inference uses softmax(logits+log FIT class prior) to weight means. Labels and masks enter only training losses and scoring, never inference. Initial expected correction exactly zero.
Risk control: all-valid-pixel MSE/25 only.
State arm: same risk +.25 balanced class CE +.25 balanced conditional-mean MSE/25. Inverse FIT class-prior weighting gives equal aggregate class contribution in auxiliary losses. Priors and mean initializers computed on full FIT only.
Smoke: verify exact zero initial output, finite training update and nonzero backbone gradient; save exact initial state before updates.
Selection: minimum mean full-monitor dual-band RMSE including C82, eval each epoch, minimum4epochs, stop when no improvement for3epochs; max8. Also report state/conditional diagnostics at each epoch, separately from the deployable score.
Promotion: same monitor both>=.20dB gain, then same484 confirmation both>=.30dB and paired95% CI positive, then full-native verification before extended fullTRAIN training. No official VAL for selection.
All work in CC. Only idle authorized 1/3/4 UUIDs through run_gpu.sh. No change to other tasks. This is a bounded same-data test, not expanded training.
