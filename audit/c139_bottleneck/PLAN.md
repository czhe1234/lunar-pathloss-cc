# C139：查明功率状态学习的实际瓶颈
日期：2026-11-10。所有操作在 CC。官方 VAL 不参与开发。
问题：C136 的几何和物理路径已显式计算，为什么训练和同地形之外的修正都接近零？
先做三项可改变决定的检查：
1. 将 C137 标签辅助反演的收益拆到直达测量、镜面源状态、漫散射源状态。不能把每个接收面的自由增益当成可预测物理状态。
2. 在同一个源面向多个接收面输送功率时，测量所需修正的正负冲突。检查源面统一标量是否掩盖接收方向差异。
3. 用固定数据做源状态与接收方向条件的配对对照。只有具有新增可迁移信号的输入才进入训练；不只扩宽或调融合权重。
固定：C82、C101 FIT/monitor、有效像素计分、固定候选网格及发布映射、官方 TRAIN/VAL 隔离。
晋级：原 128 地形完整图双频各降低至少 0.20 dB；冻结后 484 地形各降低至少 0.30 dB。达到后才扩训。
资源：仅空闲 UUID 对应 1/3/4；忙时只用两线程 CPU 分析。不得干预其他任务。
第一阶段是诊断，不预称改进成立，也不把反演得分当模型分数。
