# C95 观测对应归因方案

## 1. 目标
- parent=C94 原始接收单元反例；baseline=C82，现有固定候选传播计算。
- 问题=地形网格、TX 坐标、接收面、输出像素映射，哪项可解释标签弱点。
- 所有计算在 CC，发布数据只读；不读取其他 AI 代码；不使用官方 VAL；满足位置和功率门槛前不训练。
- 本轮为竞赛诊断，不是论文写作，无论文大纲或实验矩阵。

## 2. 比较边界
固定原版 Sionna RT 1.1.0、标称 4e9 初始方向、单个 iso/V 天线、同一 H/TX 发布数据。逐因素改动并保存逐像素结果。双频分别评价。
选型阶段使用已研究的 C94 60 块地形。最终确认另取 C93 预选 H/TX 窗口中的其他地形。候选冻结前不读取本轮确认输出和标签。
功率域/dB 域、零值、供体支持分母分开，不通过夹断零值制造反例。
允许使用少量真值辅助上界诊断，但不能把它称为输入可实现修复或确认成绩。

## 3. 检查分支
| ID | 问题 | 单独改动 | 有效证据 |
|---|---|---|---|
| source | 现有实现是否误复现原版 | 源码/方向与原版完整小场景交叉核对 | 已有直达量及单位一致 |
| pixel | 256 网格查询坐标或方向是否错误 | 查询范围、像素中心、轴/翻转，只变输出取样 | 弱点空间对应在留出地形稳定改善 |
| tx | TX 的三维位置是否不符 | 整数/连续 x/y、地形插值/取整 z，分别变动 | 同一修复同时减少反例与误报 |
| mesh | 地形网格是否不符 | 255/256 间距、对角线、连结方式 | 同上 |
| rx | +1m 平移面及首个交点是否对应标签 | 接收面偏移、法向、自交/多次相交 | 同上 |
| confirm | 修复是否泛化 | 从选型冻结一个输入可实现候选 | 弱点定位和功率均提升，正常点不恶化 |

## 4. 假设与失败条件
若逐路径非负约束仍矛盾，优先查几何与观测链。
若只把直达普遍减弱，反例会减少但定位 AP/正常点误差恶化，该候选失败。
若需逐像素按标签选位移，该结果仅为上界，不作为修复。
若合理单因素候选都失败，保留不能定位到唯一环节的结论；不盲目训练。

## 5. 资产
CC 固定原版源码、C93 地形与连续窗口、C94 原始供体值、../data 顶层发布数组。外部资料只限官方原始生成流程。
原版稀疏初始方向子查询在 CPU 完成，不能改变方向归一化和多次穿越的语义。
当前无技能所列 bash_exec/artifact/memory 工具，以现有 SSH 命令日志、JSON 和 CC 报告保存同等必要记录。

## 6. 执行与监测
先运行数值和坐标交叉检查，再在少量选型图测耗时并运行单因素筛查，冻结后确认。长运行按 <=60秒向用户报告新结果。
每阶段逐像素 NPZ 与 JSON 保存。检查进度/退出码/有限值/分母，失败不删除。

## 7. 汇报与门槛
同时报告直达过强反例数、弱点定位 AP/精确率/召回、弱点功率 MAE、正常点误差和完整同面板误差。
只有输入独立确定的修复在确认地形改善弱点位置与功率，并计入误报后仍有明确收益，才考虑训练。
不得把本轮抽样诊断成绩称作官方完整验证分数。
